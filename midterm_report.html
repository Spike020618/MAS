研究问题与场景

多 Agent 系统不缺输出，缺的是对输出过程的约束和解释。

多 Agent 共识难题

  • 能力异质，结论质量不稳定
  • 深度推理有成本，低努力和复制有诱因
  • 多数投票可能放大错误共识
  • 证据、异议和信誉通常不可见

影视搜推中的对应问题

  • 复合偏好需要多角色理解
  • 候选同时受类型、年份和事实约束
  • 生成式理由容易超出目录证据
  • 用户需要知道推荐为什么成立
共识不是让所有 Agent 说同一句话，而是形成带证据、带异议、带信誉变化的可执行决策。

AEIC：把语义判断变成可观测报告

每个 Agent 将自然语言判断拆成四个可解析、可验证的组件。

A · Assumption

Agent 采用的前提、假设或问题解释。

E · Evidence

支持判断的事实主张和证据列表。

I · Inference

从证据到结论的推理连接。

C · Conclusion

最终立场、答案和可提取决策。

质量信号

IC：推理—结论一致性EC：证据—结论支持EQ：证据质量EV：跨 Agent 证据一致

重要认识

AEIC 提供稳定的行为接口和结论抽取能力，但同模型下“逻辑自洽”不等于“事实正确”。因此机制仍需验证、证据和异议。

博弈模型与共识形成

Leader 先公开机制规则，Follower 观察规则后选择行动，再生成 AEIC 报告。

LEADER公开契约公布收益线索、成本、验证规则和资源预算。
›
FOLLOWER行动选择low-effort / AEIC-effort / verify / defer-imitate。
›
REPORT结构化报告假设、证据、推断、结论、效用、置信度。
›
CONSENSUS权重与信誉更新证据加权聚合，保留异议并形成最终决策。

Follower utility

收益 − 成本

努力不是免费的，行动会改变资源消耗。

Leader objective

质量 + IC

同时关注决策质量与高质量行为是否获得影响力。

Consensus output

Top-K

带证据、异议、Agent 贡献和信誉变化。

通信拓扑与动态调节

拓扑是信息结构和成本控制变量，机制主线仍是 Agent 行为与共识质量。

Parallel / Sequential

独立推理或链式传递，适合比较信息可见性和顺序影响。

Star / Hierarchical

中心或分层聚合，强调局部共识和汇总效率。

Debate

多轮互见，观察立场改变、从众和死锁风险。

动态行为指标

SCR：立场变化率MR：多数比例CS：收敛速度

根据群体状态区分健康收敛、谄媚收敛和死锁，并调整反馈强度。

研究定位

拓扑实验解释“信息如何流动、成本如何变化”；不能替代公开契约对 follower 行动响应的核心验证。

稳健性、泛化与不能过度宣称的部分

把失败边界放在主叙事里，结论才经得起追问。

支持性证据

  • 额外 seed：85.67% vs 71.00%，+14.67pp
  • 3/4/5 Agent 质量保持 87.33%–88.67%
  • 奖励升高时高努力率单调不减
  • 成本升高时高努力率单调不增
  • 多种信息条件下行动响应方向一致

边界与修正

  • held-out GLM：69.33% vs 70.67%，未复现提升
  • 不能宣称无条件跨模型泛化
  • 不能把动态 Stackelberg 写成已完成主结果
  • 不能把每个 AEIC 字段都写成已证明必要
安全表述：在特定 DeepSeek 后端、公开 Static AEIC 规则和实验资源配置下，系统显著改变了 follower 行动并提升了 QA 决策质量。
