## 0. 一句话定位

**AEIC-Stackelberg 博弈论共识框架是"药"，学术评审是"病"**：
用框架的结构化分解能力做诊断（发现 LLM 评审团的羊群效应），
用框架的三层机制做干预（每层治一种病理），
从而把框架从"QA 上的准确率优化器"升级为"多智能体判断系统的诊断-调控基础设施"。

---

## 1. 叙事方案：三选一

### 方案A：病理驱动（diagnose-then-intervene）——当前成稿
- 主线：LLM 评审团有没有病？→ 有三种病 → 框架三层各治一病。
- 优点：问题驱动、张力强、负结果（2b 话术失败）放得自然。
- 缺点：**框架存在感弱**——读者前几页看到的都是"评审病态"，AEIC/Stackelberg 像事后拿出来的工具。你之前的疑虑正源于此。

### 方案B：框架驱动（framework stress-test）
- 主线：我们有个博弈论共识框架（QA 已验证优化能力）→ 拿评审做压力测试 → 框架的诊断能力发现问题 → 三层机制治疗。
- 优点：框架是绝对主角，AEIC/Stackelberg/路由贯穿全文。
- 缺点：像技术报告，故事张力弱；"病"的震撼力被稀释。

### 方案C：框架即诊断器+治疗器（推荐）
- 主线：多智能体集体判断要同时回答两个问题——**决策对不对**（QA 已验证：87.6%）和**过程健不健康**（本文）。回答后者需要两件仪器：
  - **诊断器**：AEIC 结构化分解让"羊群效应"第一次变得可测量（少数派存活率、方差坍缩、翻转方向都是从 AEIC 的 C 字段直接读出来的）；
  - **治疗器**：Stackelberg 三层机制恰好对应三类干预位置（聚合时校准 / 讨论中调控 / 逐实例路由）。
- 叙事弧：
  1. 集体判断的行为维度被忽视（引言钩子）
  2. 我们的框架天然自带诊断仪器（AEIC 的 C 字段）和治疗仪器（三层）
  3. 诊断结果：三种病理 + 跨模型相反吸引子（震撼结果前置）
  4. 干预结果：一胜一负一省（校准胜、话术负、路由省）——机制类别↔病理映射
  5. 教义：校准优先 + 行为健康是主终点
- 优点：既保住方案A的故事张力，又让框架从"工具箱"升格为"仪器"——**没有 AEIC 就没有这次诊断，没有三层就没有这次干预**。贡献归属清晰。
- 缺点：引言前两段要重写（当前版引言是"评审开场"，要改成"框架+两个问题开场"）。

**我的推荐：方案C。** 它直接回应你"我们不是AEIC和博弈吗"的疑虑。

### Study 1 诊断（DeepSeek-V3，300篇=100×3层，5评审/篇）

**金句：能力不抗 herding，能力只选择吸引子。**（R1 推理最强、坍缩最狠）

### Study 2 三层干预（测试集150篇）
- 2a 校准聚合：τ=+1.04、γ1=+1.09；明确接收层 2%→38%（vs 多数投票）；总体 64.7%；诚实基线：重阈值均值 66.7%。结论=**校准必要且近乎充分，形式不拘**。
- 2b 行为调控（负结果）：89/300 触发、173人次；消灭率 78→71%；坚持率 28→29%；翻转仍 87:1；决策 59.7→60.7（安全达标）。结论=**话术敌不过从众先验，调控须作用于机制/结构**。
- 2c 路由：router 64.7%@6.6调用（-56%成本）；成本敏感 64.7%@5.3；oracle 74.7%@5.3；动作分布 124 θ*-独立 / 22 调控辩论 / 4 其他。结论=**审议是按需资源**。

### QA 旧结果（引言/讨论引用，不进主实验）
- 路由 87.6%（+4.5pp over 最佳固定拓扑，oracle 92.9%）
- 结构化提取 +28pp（C字段 76.9% vs I字段 48.9%）
- 质量信号失效（衡量连贯性非正确性）→ 引出转向行为调控的动机

## 3. 逐节内容蓝图（方案C）

### 标题（候选）
1. 《诊断后干预：博弈论多智能体LLM共识框架在自动化学术评审中的验证》（当前）
2. 《可测量才可调控：AEIC-Stackelberg框架对LLM评审团羊群效应的诊断与干预》
3. Making Herding Measurable: A Game-Theoretic Framework Diagnoses and Treats LLM Review Panels

### 00 摘要（~250词，四拍）
1. 问题：集体判断的行为健康被忽视；人类委员会的 herding 是否存在于 LLM 面板，无配对诊断。
2. 我们的仪器：AEIC 分解（C字段=立场探针）+ Stackelberg 三层（=三个干预位置）。
3. 诊断：三大病理+跨模型相反吸引子（最硬数字各给一个：96:0、-51%、R1坍缩76%）。
4. 干预与教义：校准胜（2→38%）/话术负（78→71%）/路由省（-56%）；校准优先+行为健康主终点。

### 01 引言（新开场，方案C的核心改动）
- P1 钩子：多智能体LLM系统都在做集体判断，但评估只看"决策对不对"。
- P2 两个问题并列：决策质量（QA 已验证框架 87.6%）vs 行为健康（本文）。人类委员会 herding 已知；LLM 面板未知。
- P3 为什么需要仪器：herding 藏在自由文本里，不可测。AEIC 的 C 字段让它可测（+28pp 提取可靠性）；三层机制让干预有落点。
- P4 诊断结果速览（Study1+跨模型，各一句）。
- P5 干预结果速览（2a/2b/2c，各一句）+ 机制类别↔病理映射。
- P6 贡献三条：
  1. 大规模配对诊断（行为健康指标远敏于决策准确率）
  2. 跨模型相反吸引子（方向依赖模型、能力与坍缩共现）
  3. 校准优先干预教义（机制类别↔病理的映射图谱）
