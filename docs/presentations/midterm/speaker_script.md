# 《博弈驱动的去中心化语义共识机制及在影视推荐中的应用》中期汇报讲稿

建议时长：20–25 分钟。实验部分是重点，方法和系统架构只讲理解结果所需的信息。

## 第 1 页｜封面

各位老师好，我汇报的题目是**博弈驱动的去中心化语义共识机制及在影视推荐中的应用**。这个课题关注的不是简单增加 Agent 数量，而是一个更早的问题：在生成答案之前，怎样通过公开规则影响 Agent 的行动选择，让完整推理、证据验证和最终共识都可以被观察和评价。这里的去中心化是决策与语义报告层面的模拟去中心化：多个 Agent 基于局部状态独立行动和报告，统一程序只负责同步、规则执行与日志复现。中期阶段已经完成方法设计、主体实验、英文论文以及影视推荐系统的主链路。

## 第 2 页｜研究内容与当前进展

先概括一下目前的工作。第一部分是**机制设计**：我们提出 AEIC 报告接口，定义公开合同、行动空间、验证和信誉更新。第二部分是**实验验证**：完成 8 组实验，共 5,850 个问题级样本，覆盖主效应、奖励成本响应、信息环境、消融、稳健性和跨模型验证。第三部分是**应用系统**：已经实现影视目录检索、多角色审议、Top-K 输出和运行记录。整项工作的主线始终一致，也就是从公开规则出发，观察 Agent 怎样选择行动，再分析这种行动是否改善集体决策。

## 第 3 页｜为什么多数投票还不够

多 Agent 系统通常只评价最后的多数票，但相同的结果可能来自完全不同的过程。一个 Agent 可以独立推理并验证证据，也可以只给短答案，甚至复制其他 Agent 的结论。传统聚合把这些行为都当成一张票，所以无法区分**独立证据形成的一致**和**低成本模仿形成的一致**。另外，规则如果在回答生成后才出现，只能评价文本，不能证明 Agent 对规则产生过响应。所以本文研究的重点不是“怎样投票”，而是“投票之前，Agent 为什么愿意投入更高成本，产生可验证的信息”。

## 第 4 页｜AEIC-MD 总体框架

这张图是论文方法的总体框架。最上方给出任务、公开合同、Panel 配置和信息规则。左侧每个 Follower Agent 依次完成观察、选择、执行和报告；中间的控制面先公开规则，再根据 Agent 声明的行动路由到不同资源路径；报告统一进入 AEIC 接口，并在执行后结算信用和成本。右侧是多轮同步协作以及最终聚合。需要强调的是，**影视系统不是第二个独立创新点**，而是把同一套机制放进真实检索、约束验证和推荐排序流程中进行系统实现。

## 第 5 页｜AEIC 结构化报告

AEIC 分别表示 Assumption、Evidence、Inference 和 Conclusion。Assumption 记录 Agent 怎样理解问题；Evidence 记录支持判断的事实；Inference 记录证据到结论的推理关系；Conclusion 提供可稳定抽取的最终立场。这个结构不是为了让输出更整齐，而是为了把原本不可观察的推理过程转换成可以解析、比较和验证的报告空间。系统因此能够识别字段是否完整、证据是否新增、结论是否发生翻转。不过 AEIC 完整不等于事实一定正确，所以它还需要与外部验证、资源记录和最终任务标签共同使用。

## 第 6 页｜公开合同与行动选择

机制成立的关键是**时间顺序**。Leader 必须先公开信用规则、行动成本、信息可见范围和验证预算；Follower 看到规则以后，再从 Low、AEIC、Verify 和 Imitate 中选择行动。行动不是生成结束后的标签，而是会真实触发不同的提示、Token 上限和验证流程。报告生成后，系统才计算信用、扣除成本并更新状态。这样我们才能检验一个明确问题：当公开奖励或者成本发生变化时，Agent 的行动分布是否随之变化。接下来实验部分就是围绕这个可观察的 follower response 展开。

## 第 7 页｜实验要回答的三个问题

实验围绕三个研究问题。第一，公开规则能否改变 Agent 的行动选择，也就是高资源行动率是否变化。第二，行动变化是否进一步改善集体决策，并付出怎样的资源代价。第三，这个效应是否符合奖励增加、成本增加时的方向预期，并能否在不同信息环境、Seed、Panel 规模和模型配置下保持。任务使用 StrategyQA、MMLU-Hard 和 TruthfulQA，各 150 题，共 450 道测试题。三类任务分别覆盖多步常识、专业知识和误导性前提判断。

## 第 8 页｜主实验采用问题级配对设计

主实验采用问题级配对设计。对于同一道题，模型配置、随机设置、5 个 Agent、3 轮同步审议、信息策略和最终聚合方式保持一致，唯一改变的是 Agent 在行动前看到的公开规则。No Mechanism 不提供显式信用；Outcome Only 只奖励最终答案正确；Static AEIC 奖励报告结构完整和结论明确。Outcome Only 是关键控制组，因为它可以区分“只要提到奖励就会提高表现”和“可执行的过程规则改变了生产行为”。主实验一共形成 1,350 个问题—条件记录和 20,250 个 Agent-Round。

## 第 9 页｜行为、决策与资源三类指标

评价指标分成三类。行为指标是高资源行动率，预先定义为选择 AEIC 或 Verify 的 Agent-Round 比例。决策指标是问题级准确率，从第三轮每个 Agent 的 Conclusion 字段提取立场，再做多数投票。资源指标包括 Token、调用次数和延迟，用来避免把额外计算带来的提升描述成零成本收益。统计上，相同问题在不同条件下逐题配对，最终正确率使用 Exact McNemar 检验，并在预设比较族内进行 Holm 校正，同时报告分域结果和稳健性分析。

## 第 10 页｜四类扩展实验

主实验之外安排了四类扩展实验。奖励—成本扫描检查 Agent 是否按机制预期响应；受控信息环境分别加入证据、社会立场、复制压力和反证，观察同伴信息如何影响行动；额外 Seed 和 3、4、5 Agent 设置用于检查结果稳定性；最后通过 AEIC 字段、历史策略消融和 held-out 模型配置限定结论边界。这些实验承担的作用不同：主实验给出确认性效应，扩展实验解释机制和适用范围，不能把所有结果简单合并成一个更大的正结果。

## 第 11 页｜主实验总体结果

这是最核心的结果。No Mechanism 下高资源行动率只有 0.46%，Static AEIC 下提高到 56.93%，增加 56.47 个百分点。多数投票准确率从 68.00% 提高到 82.22%，增加 14.22 个百分点，Holm 校正后的 McNemar 检验为 1.23×10 的负 11 次方。相比之下，Outcome Only 的准确率是 67.33%，与无机制没有显著差异，p 值为 0.780。所以结果不能概括成“一般奖励让模型更认真”，而是**可观察、可执行的过程规则改变了行动和集体结果**。

## 第 12 页｜三个任务域的分域结果

总体提升并不是三个任务域平均发生的。StrategyQA 从 73.33% 提高到 77.33%，增益 4 个百分点；MMLU-Hard 从 71.33% 提高到 91.33%，增益 20 个百分点；TruthfulQA 从 59.33% 提高到 78.00%，增益 18.67 个百分点。高资源行动率的提升也分别是 43.51、73.69 和 52.22 个百分点。这个异质性非常重要，所以论文没有把总体 14.22 个百分点写成任务无关常数，而是明确报告：机制对高难知识推理和真实性判断的帮助更明显。

## 第 13 页｜奖励与成本响应

这一页检验行动变化是否符合机制的方向预期。奖励尺度从 0.05 提高到 0.5 时，三个数据集的高资源行动率都单调上升，汇总结果从 49.42% 提高到 72.84%。努力成本倍率从 0.5 提高到 1.5 时，高资源行动率则从 69.51% 下降到 53.78%，三个任务域都没有出现反方向变化。这说明 Agent 的行动不仅在 Static AEIC 条件下发生一次性改变，而且会对公开奖励和成本作方向一致的响应。不过这组数据用于机制检查，不作为第二个确认性主效应估计。

## 第 14 页｜四种信息环境

这里改变的是 Agent 在后续轮次能够看到的同伴信息。在新增证据条件下，准确率从 72.0% 提高到 83.3%；只给社会多数立场时，从 74.7% 提高到 84.0%；存在复制压力时，从 68.0% 提高到 90.0%；提供立场相反的证据时，从 70.0% 提高到 82.0%。四种情况下 Static AEIC 都明显提高了高资源行动率。这组结果说明，报告接口在不同信息结构中仍然具有行为作用，但不能据此声称所有信息干预本身都会提高准确率。

## 第 15 页｜Seed 与 Panel 规模稳健性

两个额外 Seed 上，无机制准确率为 71.00%，Static AEIC 为 85.67%，增益 14.67 个百分点，Holm 校正后的 p 值为 2.40×10 的负 9 次方，主方向得到复现。Panel 规模从 3 个、4 个增加到 5 个 Agent 时，Static AEIC 的准确率分别为 88.67%、87.33% 和 88.67%，没有观察到明显退化。所以当前结果并不依赖单一采样批次，也不只在固定的五 Agent 配置下成立。

## 第 16 页｜字段与历史策略消融

消融结果需要谨慎解释。完整 AEIC 以及 EIC、AIC、AEC、AEI 等去掉单个字段的变体，准确率都在 87.33% 到 90.00% 之间，没有出现一致下降。full、reset、hidden 和 shuffled 四种历史策略也处于 84.67% 到 90.00% 之间。所以这组实验支持的是整体机制和若干变体都能维持较高表现，而不是证明四个字段逐项不可缺少。论文中必须主动限制这个结论，避免把描述性消融夸大为单组件的因果必要性证明。

## 第 17 页｜跨模型验证

这一页要先说明准确的模型配置。主实验中，行动选择和 AEIC 路径使用 API 标识 `deepseek-chat`，Verify 路径使用 `deepseek-reasoner`，Low-effort 路径使用 `glm-4-flash`。held-out 实验则让 `glm-4-flash` 承担行动选择和报告生成。在这个配置下，高资源行动率只从 0.58% 变为 0.93%，准确率从 70.67% 变为 69.33%，两项都不显著。这说明同一合同文字不能自动成为跨模型通用激励，后续需要针对具体模型策略做合同校准。

## 第 18 页｜实验结果总结

实验部分可以归纳成四条结论。第一，Static AEIC 在主实验配置中显著改变高资源行动，并提高多数投票准确率。第二，奖励和成本扫描与公开合同的机制预期一致。第三，结果在三个任务域、额外 Seed 和不同 Panel 规模下保持主方向。第四，`glm-4-flash` held-out 配置没有复现主效应，所以当前不支持无条件跨模型泛化。论文最终支持的是一个有边界的结论：结构化过程规则可以影响经过测试和校准的模型策略，但合同语义依赖具体模型。

## 第 19 页｜影视搜索推荐系统

系统部分用于把论文机制落到一个可运行场景中。用户先提交自然语言偏好、年份和排除条件；Planner 根据风险和预算生成执行计划；目录检索从 18,430 部 MovieLens 电影中生成真实候选；Preference、Diversity 和 Critic 三类 Agent 从不同角度生成 AEIC 报告；确定性验证器检查实体和硬约束；共识控制器再完成聚合、排序和异议保留。最终输出 Top-K、推荐理由、证据、运行记录和性能指标。系统实现验证的是同一机制，而不是新增第二个理论创新。

## 第 20 页｜系统运行过程与结果解释

这一页最终会放三张真实运行截图。第一张展示用户请求怎样变成风险等级、角色配置、验证预算和公开合同；第二张展示三个角色分别选择了什么行动、生成了什么 AEIC 内容，以及 Token 和延迟；第三张展示候选级分项得分、支持证据、残余异议和降级状态。当前先保留截图位置，是为了固定每张截图必须证明什么，而不是随意放界面效果图。正式答辩前会用主案例、分歧案例和降级案例替换这些占位框。

## 第 21 页｜已完成工作与剩余任务

目前已经完成的方法工作包括 AEIC、公开合同、行动空间和信誉机制；实验方面完成三种规则的主实验，以及奖励成本、信息环境、消融、稳健性和跨模型验证；论文方面已经形成 14 页英文完整稿；系统方面完成 MovieLens 目录处理、检索、多角色审议、共识和 HTTP 接口测试。剩余工作集中在影视离线评测、三类代表性系统案例、中文毕业论文整合和答辩材料固化。这些任务不会改变研究主线，属于应用证据和毕业交付的收尾。

## 第 22 页｜毕业设计收尾计划

后续按三步完成。第一步是影视离线评测，固定 MovieLens 目录和测试请求，对比基础检索、单 Agent 和多 Agent 共识，报告排序质量、约束满足率、证据支持率、延迟和成本。第二步以英文论文为主线整合中文毕业论文，新增系统设计与影视评测章节，不重新发明一套理论。第三步替换系统截图占位，固化 Demo、演讲稿和评审问答。原则是不再扩展新的研究方向，所有工作都直接服务于系统证据或最终答辩。

## 第 23 页｜总结

最后总结三点。第一，本文的主线是**公开规则怎样影响 Agent 行动**，不是单纯调整通信拓扑或多数投票。第二，实验表明 Static AEIC 在主实验配置中显著提高高资源行动和集体准确率，同时奖励成本、信息环境和稳健性实验给出了机制解释；跨模型结果又明确限定了结论范围。第三，影视搜索推荐系统把同一机制落实到可检索、可验证和可解释的应用流程中。当前方法、实验、英文论文和系统主体已经完成，下一阶段集中完成应用评测与答辩收口。谢谢各位老师，欢迎提问。
