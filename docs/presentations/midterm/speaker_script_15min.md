# 中期汇报十五分钟讲稿

目标时长：正文约 14 分 30 秒，预留约 30 秒用于翻页、停顿和现场节奏调整。讲稿按当前 30 页 PPT 编排，答辩时不必逐字朗读，优先讲清每页的加粗结论。

## 1｜封面（15 秒）

各位老师好，我是马天成，导师是高志鹏老师。我的毕业设计题目是**博弈驱动的去中心化语义共识机制及在影视推荐中的应用**。本次汇报主要介绍研究问题、机制设计、实验结果、系统实现以及后续计划。

## 2｜汇报内容（20 秒）

汇报分为六部分，但整项工作只有一个核心创新点：**博弈驱动的去中心化语义共识机制**。前半部分介绍问题、AEIC 报告空间和博弈共识过程；随后用系统实验验证机制；最后展示影视推荐系统如何完成应用验证，以及目前的成果和后续安排。

## 3｜研究背景（40 秒）

研究背景来自四条脉络。第一，大模型多智能体已经从角色分工发展到辩论、同侪评审和异构 Agent，但仍然存在从众、同质化和通信成本。第二，CoT 和图式推理提高了复杂任务能力，却不能自动消除幻觉和不可验证推理。第三，现有语义一致性研究更多关注单模型输出，多 Agent 如何在自然语言空间形成可计算共识仍不充分。第四，更强基模可以提高能力上限，但无法自动决定什么时候值得投入更多 Token、验证和延迟。因此本文关注的是：**在基模不变和预算有限的情况下，能否通过公开机制控制 Agent 的行动与信息生产。**

## 4｜研究内容与创新定位（35 秒）

本文不是简单增加四个 Prompt 字段。与多数投票相比，我们研究的是投票前的行动选择；与普通结构化 Prompt 相比，AEIC 是可以解析并进入信用结算的报告空间；与结果奖励相比，合同在生成之前公开；与拓扑和 Debate 方法相比，本文直接控制 Prompt、Token 和验证路径。围绕这一创新点完成三部分内容：机制设计、实验验证，以及影视推荐中的系统应用。

## 5｜总体框架与去中心化口径（30 秒）

框架中，每个 Agent 基于自己的局部状态观察合同、选择行动并生成报告，再通过受控的信息交换形成集体结论。这里的“去中心化”是**决策和语义报告层面的逻辑去中心化**：不存在一个中央 Judge 替所有 Agent 生成答案。当前统一程序仍负责同步、合同执行、聚合和日志记录，因此更准确地说是模拟去中心化，而不是已经实现跨机器 P2P 网络。

## 6｜AEIC 报告接口（30 秒）

AEIC 分别表示 Assumption、Evidence、Inference 和 Conclusion。A 记录任务前提和约束，E 记录事实主张和来源，I 记录证据如何支持判断，C 给出可解析的最终立场。它的价值不是让文本更整齐，而是把原本自由、难以比较的推理过程转换为统一报告接口，使系统能够保留证据增量、立场变化和异议来源。

## 7｜报告信号与机制结算（35 秒）

当前代码首先检查 AEIC 完整度，并分别保留四个字段是否存在；随后解析 Conclusion 的任务立场。对于能够观察历史的合同，还计算 Evidence 相对可见证据的 Token 新颖度、验证证据、有效纠正和无支持翻转。不同合同选择不同信号加权得到信用，再减去行动成本形成效用。这里要强调：**结构完整和证据新颖不等于事实正确**，它们是机制信号，最终效果仍然由任务准确率独立评价。

## 8｜博弈时序（20 秒）

机制成立的关键是时间顺序：Leader 先公开信用、成本、信息可见性和验证预算；Follower 看到规则后，再选择 Low、AEIC、Verify 或 Imitate。行动会真实触发不同的 Prompt、Token 和验证流程，因此实验观察到的是合同之后的 follower response，而不是生成结束后的事后标签。

## 9｜合同、行动与净效用（35 秒）

合同记为 m，由信用规则、行动成本、信息策略和验证预算组成。Follower 在四类行动中选择，使预期信用减去可见成本的净效用更高：Low 对应快速低成本判断，AEIC 对应完整报告，Verify 增加核验与修订，Imitate 则利用可见的同伴信息。本文不假设语言模型精确计算闭式最优解，而是检验可观察预测：奖励提高时高资源行动应增加，成本提高时应减少。

## 10｜从博弈到共识的完整过程（35 秒）

这一页把机制完整串起来：合同承诺、行动选择、AEIC 报告、验证与信誉结算，最后才是集体聚合。主实验最终仍然使用多数表决，但创新发生在投票之前——公开规则改变了哪些信息会被生产、验证并带入最终决策。因此共识不是一个孤立的投票算子，而是前面整条博弈过程的结果。

## 11｜实验问题与数据集（25 秒）

实验围绕三个问题展开：第一，公开规则能否改变 Agent 的行动；第二，行动变化能否改善集体决策；第三，响应是否符合奖励和成本预测，并在不同信息环境和随机条件下保持稳定。实验覆盖 StrategyQA、MMLU-Hard 和 TruthfulQA，每个数据集 150 题，共 450 道题。

## 12｜主实验设计（30 秒）

主实验采用问题级配对设计。对于同一道题，模型配置、五个 Agent、三轮同步审议、信息策略和多数聚合保持一致，只改变生成前公开的规则。No Mechanism 不提供显式信用；Outcome Only 只奖励最终正确；Static AEIC 奖励可观察的报告过程。Outcome Only 是关键对照，它用于排除“只要出现奖励语言，模型就会更认真”的解释。

## 13｜指标与统计方法（25 秒）

指标分为三类。行为指标是 AEIC 或 Verify 所占的高资源行动率；决策指标是第三轮多数结论的准确率；资源指标包括 Token、调用次数和延迟。由于不同条件使用相同问题，准确率使用问题级配对的 Exact McNemar 检验，并在比较族内进行 Holm 校正，同时报告分域和稳健性结果。

## 14｜扩展实验设计（20 秒）

主实验之外还有四类扩展：奖励—成本扫描检验方向性响应；四种信息环境检查不同同伴信息条件；额外 Seed 和不同 Panel 规模检查稳定性；字段组合和历史策略扰动检查机制对局部配置变化的鲁棒性。它们用于解释主效应，而不是替代主实验。

## 15｜确认性主结果（45 秒）

这是最核心的结果。No Mechanism 下高资源行动率只有 **0.46%**，Static AEIC 下提高到 **56.93%**，增加 56.47 个百分点。多数投票准确率从 **68.00% 提高到 82.22%**，增加 14.22 个百分点，Holm 校正后的 p 值为 1.23×10 的负 11 次方。相比之下，Outcome Only 的准确率是 67.33%，没有显著改善。因此能够支持的结论不是“一般奖励有效”，而是**可执行的过程规则改变了行动，并在当前配置下改善了集体结果**。同时，这种提升伴随更多计算资源，不能描述为零成本收益。

## 16｜三个任务域的结果（25 秒）

三个任务域均有提升，但幅度明显不同。StrategyQA 提升 4 个百分点，MMLU-Hard 提升 20 个百分点，TruthfulQA 提升 18.67 个百分点。这说明总体 14.22 个百分点并不是任务无关常数，机制收益与任务对知识核验、选项比较和反诱导推理的需求有关。

## 17｜分域异质性解释（40 秒）

StrategyQA 的基线较高，高资源行动响应也最小，额外验证的边际价值相对有限。MMLU-Hard 需要知识提取、选项比较和排除干扰项，同时出现最大的行动变化和约 69.8% 的相对错误减少。TruthfulQA 常包含诱导前提，显式写出假设、证据和反证有助于避免常见错误信念，相对错误减少约 45.9%。不过这些是与结果一致的机制解释，不是独立因果证明：每个域只有 150 题，当前没有把任务属性本身识别为增益原因。

## 18｜奖励与成本响应（30 秒）

奖励尺度从 0.05 提高到 0.5 时，汇总高资源行动率从 49.42% 单调上升到 72.84%；成本倍率提高时，高资源行动率从 69.51% 下降到 53.78%，三个任务域方向一致。这与合同模型的两个基本预测相符，说明主实验中的行动变化不是一次性的格式服从，而是会随公开激励条件发生系统变化。

## 19｜不同信息环境（25 秒）

我们进一步控制 Agent 能看到的信息，分别加入新增证据、社会多数立场、复制压力和反证。在四种环境中，Static AEIC 都明显提高高资源行动率，本组实验的准确率也保持提升方向。这说明报告接口不仅在单一信息结构下可用，也能在存在同伴影响和反证的情况下继续组织行为与审计。

## 20｜Seed 与 Panel 规模稳健性（20 秒）

在两个额外 Seed 上，Static AEIC 相对无机制的准确率仍提高 14.67 个百分点。Panel 从 3 个、4 个增加到 5 个 Agent 时，准确率分别为 88.67%、87.33% 和 88.67%。因此当前主方向不依赖某一次采样，也不只成立于固定的五 Agent 设置。

## 21｜组件与历史扰动（25 秒）

去掉单个 AEIC 字段或者改变历史可见策略后，各变体准确率仍处于较高区间，没有出现明显退化。更合适的解释是：统一、可解析的过程报告和完整机制具有较好的配置鲁棒性。当前结果不支持把某一个字段单独宣称为不可替代组件，也不影响对整体机制主效应的判断。

## 22｜完整证据链（30 秒）

现在可以把实验串成一条证据链。确认性主实验说明合同同时改变行动和准确率；奖励与成本扫描给出方向一致的行为响应；四类信息环境说明结果不依赖单一同伴信息结构；额外 Seed、Panel 规模以及局部配置扰动提供稳定性支持。因此主体结论不是来自某一个漂亮数字，而是由主效应、机制响应和稳健性共同构成。

## 23｜实验结论（30 秒）

实验支持四点。第一，Static AEIC 显著提高高资源行动率。第二，集体准确率在主实验中同步提升，而 Outcome Only 没有得到同样结果。第三，奖励、成本和信息环境结果与机制预期一致。第四，主方向在任务、Seed 和规模变化下保持稳定。论文因此主张的是：**公开的 AEIC 过程规则能够诱导可观察的信息生产，并在已测试配置下改善集体决策。**

## 24｜影视推荐系统架构（25 秒）

系统部分用于验证同一机制，而不是另起一个创新点。系统基于 18,430 部 MovieLens 电影，贯通自然语言请求、风险与预算规划、真实候选检索、Preference、Diversity、Critic 三类 Agent、AEIC 审议、硬约束验证和 Top-K 输出，并保存完整 Trace。

第三张截图展示候选级共识。每部影片都分解为检索相关、决策共识和证据共识，并保留接受证据和报告层异议。所有截图来自同一个 request id，可以通过保存的 Trace 复核。

## 28｜用户侧最终推荐（15 秒）

最后，系统把内部审议转化为用户可读的 Top-3 推荐卡，展示影片信息、推荐理由和约束满足状态。用户不必阅读内部 Trace，但每条理由仍可回溯到目录证据，完成从机制审议到应用输出的闭环。

## 29｜已完成工作与未来计划（30 秒）

目前已经完成 AEIC 与公开合同设计、三域确认性主实验、扩展实验、统计分析、英文论文和影视系统主链路，真实系统案例也已经固化。未来工作不是扩展新的研究方向，而是沿现有主线收口：估计 follower 响应面并搜索有限合同空间；增强短期偏好、长期画像和混合召回；随后完成毕业论文整合、系统验收和答辩材料。

## 30｜成果与时间安排（40 秒）

截至目前，论文已经撰写完毕并正在投递，系统专利文本已经完成。十月集中完成两项增强：有限合同空间的经验 Stackelberg 求解，以及个性化召回和影视应用评测；十一到十二月推进论文、专利和毕业论文整合；之后根据反馈完善系统和必要分析，答辩前完成论文定稿、系统验收与材料归档。最后总结：本文把研究重点从最终投票前移到 Agent 的行动选择，用公开合同组织可验证的信息生产，并通过实验和影视系统完成验证。谢谢各位老师，欢迎提问。
