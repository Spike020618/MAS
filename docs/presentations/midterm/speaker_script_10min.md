# 中期汇报十分钟讲稿

目标时长：约 9 分 30 秒至 10 分钟。不要逐字朗读页面，只讲加粗结论。

## 1｜封面（10 秒）

各位老师好，我汇报的题目是**博弈驱动的去中心化语义共识机制及在影视推荐中的应用**。本次主要汇报研究背景、机制设计、实验结果和系统实现。这里的去中心化是决策与语义报告层面的模拟去中心化：多个 Agent 基于局部状态独立行动和报告，统一程序只负责同步、规则执行与日志复现。

## 2｜研究内容与进展（15 秒）

目前已经完成三部分工作：提出 AEIC机制 机制；完成 8 组实验和英文论文；实现影视搜索推荐系统主链路。整项工作的主线是：**公开规则如何改变 Agent 行动，并进一步影响集体决策**。

## 3｜研究背景（20 秒）

传统多 Agent 方法主要看最终多数票，但相同结果可能来自独立验证，也可能来自低成本模仿。本文关注投票之前的行为：怎样让 Agent 愿意选择完整推理和追加验证，并让这些行动可观察、可评价。

## 4｜创新点对比（20 秒）

本文创新不是简单增加 AEIC 四个字段。与多数投票相比，我们研究生成前的行动选择；与结构化 Prompt 相比，AEIC 是可结算报告空间；与结果奖励相比，合同先公开且行动真实控制 Prompt、Token 和验证路径；与拓扑方法相比，我们控制是否生产独立可检查的信息。核心是把报告结构、承诺时序、资源执行和配对识别连成一个可证伪协议。

## 5｜总体框架（20 秒）

Leader 在生成前公开信用、成本和信息规则；Follower 看到规则后选择真实资源路径；报告进入 AEIC 接口，再进行多轮协作和聚合。影视系统用于实现和验证这套机制，不是第二个独立创新点。

## 6｜AEIC（15 秒）

AEIC 分别记录假设、证据、推理和结论。它的作用不是规范排版，而是把自由文本转换成可以解析和验证的报告，让系统看到 Agent 如何形成答案。

## 7｜AEIC 报告空间（20 秒）

形式上，第 i 个 Agent 的报告记为 r_i，由 A、E、I、C 四部分组成。完整度 q_comp 统计四个字段中非空字段的比例；q_C 只判断结论能否解析成任务立场。这里要强调：**结构完整不等于事实正确**，它只是把不可观察的生成过程变成可检查信号。

## 8｜博弈时序（15 秒）

关键是规则先公开、行动后发生。Agent 从 Low、AEIC、Verify 和 Imitate 中选择行动，行动会真实控制提示、Token 和验证过程，所以我们可以直接检验 follower response，而不是事后给文本打分。

## 9｜合同、行动与效用（25 秒）

Leader 公开合同 m，其中包括信用规则 g_m、行动成本 c_m、信息策略 P_m 和验证预算 B_m。Agent 在 Low、AEIC、Verify、Imitate 四种行动中选择，使期望信用减去行动成本的净效用最大。我们不假设语言模型精确求解闭式均衡，实验检验的是可观察含义：**奖励提高时高资源行动是否增加，成本提高时是否下降**。

## 10｜状态、决策与估计量（25 秒）

每轮执行后，信誉 rho 由上一轮信誉、当轮信用和行动成本共同更新，历史衰减系数 delta 取 0.9。最终答案 y-hat 是第三轮 N 个 Agent 结论的多数决策。实验核心估计量有两个：Delta_H 衡量处理合同相对对照合同带来的高资源行动率变化；Delta_Acc 衡量多数决策正确率变化。本文识别的是合同改变后黑盒策略 pi 的响应，不声称找到全局最优合同。

## 11｜实验问题（20 秒）

实验回答三个问题：规则能否改变行动；行动变化能否提高准确率；结果是否符合奖励成本预期并具有稳定性。使用三个数据集，各 150 题，共 450 道测试题。

## 12｜主实验设计（25 秒）

主实验采用问题级配对设计。同一道题保持模型配置、5 个 Agent、3 轮审议和聚合方式一致，只改变公开规则。比较 No Mechanism、Outcome Only 和 Static AEIC，共 1,350 个问题—条件记录。

## 13｜指标与统计（20 秒）

指标包括高资源行动率、第三轮多数投票准确率，以及 Token 等资源成本。准确率使用问题级配对的 Exact McNemar 检验，并进行 Holm 多重校正。

## 14｜扩展实验（15 秒）

扩展实验包括奖励成本扫描、四种信息环境、额外 Seed、不同 Panel 规模、组件消融和跨模型验证，分别用于解释机制和限定结论范围。

## 15｜主实验结果（35 秒）

这是核心结果。Static AEIC 将高资源行动率从 **0.46% 提高到 56.93%**，多数投票准确率从 **68.00% 提高到 82.22%**，提升 14.22 个百分点，校正后 p 值为 1.23×10⁻¹¹。Outcome Only 的准确率为 67.33%，没有显著改善，所以效果不能解释为一般奖励语言。

## 16｜分域结果（15 秒）

三个任务域均提升，但幅度不同：StrategyQA 提升 4 个百分点，MMLU-Hard 提升 20 个百分点，TruthfulQA 提升 18.67 个百分点。因此总体增益不是任务无关常数，在高难知识和真实性判断任务上更明显。

## 17｜分域异质性解释（30 秒）

差异可以从任务结构理解，但要区分解释和已证明结论。StrategyQA 是布尔常识推理，基线较高、高资源行动响应也最低，相对错误减少约 15%。MMLU-Hard 需要知识提取、选项比较和排除干扰项，高资源行动增加 73.69 个百分点，相对错误减少约 69.8%。TruthfulQA 常含诱导前提，显式假设、证据和反证有助于抵抗常见错误信念，相对错误减少约 45.9%。这些解释与数据一致，但每域只有 150 题，尚未做数据集与处理的交互检验，所以不能写成独立因果机制。

## 18｜奖励与成本（25 秒）

奖励从 0.05 提高到 0.5 时，高资源行动率从 49.42% 上升到 72.84%；成本倍率提高时，高资源行动率从 69.51% 下降到 53.78%。三个任务域方向一致，支持 Agent 对公开合同产生行为响应。

## 19｜信息环境（20 秒）

在新增证据、社会立场、复制压力和反证四种环境下，Static AEIC 都明显提高高资源行动率；本组实验中的准确率也分别得到提升，说明机制在不同信息结构下仍然可操作。

## 20｜稳健性（20 秒）

两个额外 Seed 上，Static AEIC 比无机制高 14.67 个百分点。3、4、5 个 Agent 条件下准确率都在 87.33% 到 88.67% 之间，主方向不依赖单次采样或固定 Panel 规模。

## 21｜消融（20 秒）

去掉单个 AEIC 字段以及改变历史策略后，准确率仍处于较高区间，没有出现一致下降。所以消融支持整体机制，但**不能证明四个字段逐项不可缺少**。

## 22｜跨模型验证（30 秒）

主实验中，选择和 AEIC 使用 `deepseek-chat`，Verify 使用 `deepseek-reasoner`，Low 使用 `glm-4-flash`。held-out 实验让 `glm-4-flash` 承担选择和报告后，高资源行动率几乎不变，准确率差值为负 1.33 个百分点且不显著。说明合同有效性依赖具体模型策略，需要后端校准。

## 23｜实验总结（25 秒）

实验支持四点：过程规则能改变行动和结果；奖励成本响应符合预期；结果跨任务、Seed 和规模保持主方向；但同一合同不能自动迁移到所有模型。本文因此给出的是**有边界的机制结论**。

## 24｜系统架构（20 秒）

影视系统基于 18,430 部 MovieLens 电影，实现请求规划、候选检索、Preference、Diversity、Critic 三类 Agent、AEIC 共识和 Top-K 输出，用真实目录和硬约束验证论文机制。

## 25｜请求与执行计划（12 秒）

第一张是真实运行的请求和计划。系统根据请求得到 high 风险、0.76 复杂度、并行审议和验证预算 3；时间线证明公开合同在所有 Agent 行动之前提交。

## 26｜多 Agent AEIC 工作台（12 秒）

第二张展示三类在线 Agent 的真实执行。它们分别消耗五千以上 Token和 5 到 7 秒；Diversity 与 Critic 各产生两份反对报告，说明系统保留真实分歧，而不是复制一致答案。

## 27｜候选级共识审计（12 秒）

第三张展示最终 Top-3。每个候选都分解为检索相关、决策共识和证据共识，并保留接受证据；四张图由同一整页真实运行裁切，另存 Trace 用于复核同配置运行。

## 28｜最终推荐效果（12 秒）

前三张图解释内部机制，这一张展示用户真正得到的结果。系统把同一次共识运行转化为三张推荐卡，提供影片信息、推荐依据和约束满足提示，同时保留理由到目录证据的追溯关系。

## 29｜当前进展（15 秒）

方法、主实验、扩展实验、统计分析、英文论文和系统主链路已经完成。剩余工作是影视离线评测、系统案例截图、中文论文整合和答辩材料固化。

## 30｜后续计划（10 秒）

后续依次完成影视评测、中文论文和答辩材料，不再新增研究方向，所有工作都服务于应用证据和最终交付。

## 31｜总结（15 秒）

最后总结：本文把研究重点从最终答案聚合前移到 Agent 的行动选择；实验表明 Static AEIC 能在主实验配置下提高高资源行动和集体准确率，同时明确存在模型依赖边界；影视系统完成了机制的应用实现。谢谢各位老师。
