# 博弈主线再设计：文献依据与验收计划

日期：2026-10-24。用户约束：导师要求包含实质博弈论；保留一个研究内容；旧工作作为可核查基础，而非用工作量替代新方法效果。

本文补充此前《同模型机制验证：文献调研与方向建议》。它是研究设计建议，不是预注册、已实现算法或正向实验报告。本轮没有调用模型API，不修改冻结实验和正式题目。

## 1. 建议论题与主线

工作论题建议：**证据约束的多智能体语义共识博弈及其求解方法研究**。

正式开题题目《博弈驱动的去中心化语义共识机制及在影视推荐中的应用》暂不修改。这里仅明确研究部分。若采用统一进程求解，须称逻辑多主体/决策层模拟，不能宣称P2P基础设施或真实独立经济主体。

唯一研究问题：在同一模型、可比信息和预算条件下，如何协调生成判断与核查判断，形成有可计算稳定性、同时有决策增益的语义共识？

建议优先研究**求解型博弈**，而不是继续追求支付提示诱导LLM理性。模型提供可观测的生成/核查行为，显式策略模块承担优化；博弈直接参与答案决策。它与经济激励型博弈不同，必须明确口径，不将经济自主性当成已有实现。

## 2. 原始研究给出的路线选择

### A. 正则化信号博弈：优先原型

[The Consensus Game，ICLR 2024，正文§2及附录A](https://www.mit.edu/~gfarina/2024/consensus_game_iclr24/consensus_game_iclr24.pdf)将生成/判别分布构成博弈并求解排名。其关键限制是：一致不等于真值；无悔保证中的平均联合分布CCE不等于末次策略Nash。可借鉴明确策略与可计算偏离，而不是照搬结论。直接复现仅是基线，非原创。

适配判断：API环境下不要求微调或天然自利假设，比较适合先核查。风险是分布估计不可靠，以及求解结果可被更简单的概率融合替代。

### B. 证明者—验证者博弈：设计依据，不立即作为训练任务

[Learning to Give Checkable Answers with Prover-Verifier Games，2021，§3](https://arxiv.org/html/2108.12099v1)比较博弈时序与信息揭示，特定验证者先行结论依赖可实现验证协议等假设。不能把任意先后调用当作Stackelberg。后续[Prover-Verifier Games improve legibility，2024](https://arxiv.org/abs/2407.13692)包含迭代训练；不能称仅改API提示已复现。可借鉴“理由能否经受检查”，不是“理由是否四字段完整”。

适配判断：与证据核查相关，但闭源API不能直接复现原训练；纯提示替代会形成另一方法，须重新验证。

### C. 有成本信息获取的委托代理博弈：理论贴合，当前实施前提不足

[Learning to Incentivize Information Acquisition，2023，§2](https://arxiv.org/html/2303.08613v2)明确先公开评分规则，主体选择努力并报告，最后揭示结果结算；主体掌握信息结构，具有贝叶斯信念。它不是简单奖励提示模型。

[Online Information Acquisition: Hiring Multiple Agents，ICLR 2024，§2](https://arxiv.org/html/2307.06210v1)处理多个主体、相关信号和报告偏离。其信号边缘分布不受其他主体行动影响的假设，不能直接套给共享检索与互相改写报告的流程。

适配判断：只有真实或明示模拟的私有信息/主体成本/策略选择成立时才进入主线。目前已知公共固定路径与可核验成本情形，简单成本契约已复制复杂支付的行动。这条路线保留为历史理论原型与边界，不因导师要求博弈就重新追加关键票奖励。

### D. 同伴预测：暂不选为主方案

[Incentivizing Evaluation via Limited Access to Ground Truth，2016，§5及定理3](https://arxiv.org/pdf/1606.07042)在给定低成本共同信号等条件下揭示无信息均衡及简单抽查的优势。该结果不是所有同伴预测均不可能，但足以提醒我们：奖励一致或相关性，不能保证获得有用信息。与我们高度一致、同源错误和简单契约问题相吻合，不宜再从词面新颖或互相赞同构造支付。

## 3. 必须先区分的两个验收

### 数学与执行验收

给定明确游戏，策略是谁控制、何时选择、看到什么、效用如何计算、参考分布从何而来，均需可核对。用数值模块优化策略，不假设LLM自行最大化效用。

对拟报告的独立混合策略组合，检查正则化游戏的最大单边偏离收益：

R_i(π)=max_{π_i'}[U_i(π_i',π_{−i})−U_i(π_i,π_{−i})]。

只有各方R_i≤ε，才报告该具体游戏的ε-Nash证书；内层最佳响应需有准确解或可靠误差上界，枚举少量候选偏离仅是下界，不能证明无其他有利偏离。若只建立平均联合分布的CCE，就按CCE报告，不能改称Nash/Stackelberg。

若游戏改为序贯承诺，则另需完整跟随者最佳响应、领导者优化、平局规则和策略空间限定。不得以迭代先后顺序代替Stackelberg定义。

这些都是形式稳定性，不是答案正确率保证；正则化锚定错误也可能稳定地输出错误。已有一般定理应用不能冒充原创理论。

### 方法有效性验收

同模型、相同可用证据及公平成本条件下，博弈求解必须优于强简单策略，或者在预先规定的非劣范围下更省资源。必须包含相同分数与证据、移除求解器的直接选择/融合对照。否则只能证明底层信息或核查有用，不能证明游戏求解有用。

测试标签只用于离线效果评价；不能进入当前题效用、策略、先验或核查工具。算法内的“correct/incorrect”信号类别不等于当前题官方真值。

## 4. 具体工作顺序：不同时开四种博弈

### P0：一页游戏规格与接口核查

优先以正则化信号博弈为基线，写清参与者、生成/核查两种策略、候选与信息集、效用、概率估计及求解目标。此阶段先不自造支付，不强行加入预算玩家。

[DeepSeek当前官方接口](https://api-docs.deepseek.com/api/create-chat-completion/)列出输出token的logprobs/top_logprobs。但这不等于支持任意给定完整答案的强制似然评分；本轮未探测当前账户/模式，也未验证GLM。不得从参数存在推断可完整复现论文评分。

若使用单token选项编码，须检查分词、所有候选概率是否返回、顺序/编码偏差、未返回质量和非候选质量；只在选项集合内归一化是一种受限任务策略，不是原完整答案分布。若改用重复采样估计，明确其费用、平滑和估计误差；不把模型口头百分比当真实token概率。两个后端不具备等价接口时，不强称严格复制同一原算法。

输出：可执行规格、接口支持矩阵、对文献改动清单。规格未闭合不跑大批。

### P1：求解器与零API必要性检查

在已知分布的有限构造游戏验证求解、残差和退化情形。这是测试不是模型效果。

必须检查：是否只是普通加权的另一写法；对二分类是否结构性不能改变等票；是否产生符号颠倒/固定答案/弃答均衡；增加证据后是否只改变常数、对策略毫无影响；预算或成本是否只是装饰项。若可约化为简单排名，不把它包装成复杂创新。

采用同一效用与信息集比较直接最佳评分、简单融合和文献原求解。记录求解CPU时间与概率估计成本。

### P2：同模型小批量基线复现

各后端内部固定实际模型、思考模式与数据，保留普通充分推理、独立投票、生成评分、核查评分、简单融合和文献式博弈求解。复用同一候选/评分池，不为每种后处理重复调用。

旧报告缺少完整生成/判别概率，不能用旧自报置信度伪造原算法输入；可作候选诊断，不是完整免费复现。已开卷题组只作开发，不假装独立测试。

若文献基线与简单评分没有增量，先定位模型分布与核查能力，不直接扩展新证据机制。复现他人算法成功也不是我们的新贡献。

### P3：一个候选扩展——证据约束的策略协调

只研究一项新增：可追溯的主张—证据关系如何约束生成/核查之间的策略协调，避免无依据共识。证据支持程度不直接等于事实真值，无法核查不得自动当反证。

先做固定候选、固定证据池的因果干预；同证据普通裁判、证据评分直接排名、文献原博弈和新增博弈都比较，检验新增信息与求解的独立作用。再考虑取得证据的预算，不能把“核查+投票+游戏”三样放一起便宣布创新。

此处尚未确定有效新效用，必须在P0—P2结果基础上写出具体规则后冻结。本文不提供一个尚未验证却宣称最优的支付公式。若没有超过直接证据评分，停止该扩展。

### P4：独立题组与博弈证书共同验收

同时满足模型效果、同池求解必要性及游戏残差；报告两后端效应、纠正/退化、资源曲线。正式题量按配对效应与不一致率设计，不能预设小样本足以显著。能力分层预先由开发表现定义，不能事后挑较弱模型成功即删除较强模型。

无效果即保留负结果并止损，不再为了找到某种均衡挑游戏。求解型博弈若与导师期待的经济激励不同，需要在正式定题前向导师明确这一差别，而不是在论文中含混处理。

## 5. 旧工作如何形成有主次的研究积累

| 旧工作 | 新研究中的位置 | 不能承担的证明 |
|---|---|---|
| 450题联合执行配置正向结果 | 研究动机、历史基线、混杂识别 | 同模型机制净增益 |
| 主后端/成本/信息环境/规模等扩展 | 在各自配置下的探索与稳健性资料，按来源去重说明 | 对未测新算法的稳健性 |
| 60题分解、90题接口及解析审计 | 设计排除与公平对照依据 | 四字段分别不可替代 |
| 真实资源路径、封存、预算、结算 | 新实验可复用的研究基础设施 | 自然LLM自利或激励相容 |
| 势博弈与独立预算原型 | 形式化基础、协调障碍与简单契约边界 | 均衡已改善语义质量 |
| 同信息审阅、异构互补和加权失败 | 新方法必须超过的负对照及停止依据 | 删去失败后只呈现成功 |
| 正确候选覆盖与读出损失 | 解释为什么研究生成—核查协调 | 离线oracle可部署 |

正文只展示支撑最终方法选择的关键实验，其他放补充材料。旧研究与新研究版本、题型、后端、是否开卷要明确；不能累计重复题或把构造状态当独立任务量。不为了显得工作多，把所有迭代都并列为贡献。

## 6. 最终可争取的贡献，而非现成结论

1. 一个策略、信息和效用对应实际执行的语义共识博弈。
2. 一个有可计算偏离证书的求解程序，明确均衡种类及误差范围。
3. 在同模型公平对照中，验证证据约束与博弈求解各自的决策/效率增量。
4. 用旧探索和新消融解释哪些条件下有效、哪些条件下退化。

当前1—3均不能仅由本次调研视为完成。历史工作能够显著支撑研究深度，但核心贡献仍须同一方法的理论、代码与独立效果共同成立。
