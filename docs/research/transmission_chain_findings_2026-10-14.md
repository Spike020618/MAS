# 机制传导链综合分析

更新时间：2026-10-14  
数据范围：冻结主实验 `formal_v10`，450 个问题、3 个条件，共 1350 条问题级记录；补充实验另含报告接口 270 条和机制拆解 240 条。

## 一、研究问题

主实验不应只回答“最终准确率是否提高”，而应检验一条连续的机制链：

> 公开过程规则 → Agent 行动响应 → 真实资源投入 → 可核验报告 → 错误修正 → 集体决策改善

AEIC 在这条链中是可观察、可计分、可审计的报告接口。当前证据不支持把 AEIC 描述为一种仅凭字段格式就必然提高准确率的推理方法。

## 二、主结果：机制改变行动，并改善集体决策

| 指标 | No Mechanism | Static AEIC | 配对差值 |
|---|---:|---:|---:|
| 高资源行动率 | 0.46% | 56.93% | +56.47 pp，95% CI [54.13, 58.80] pp |
| 第三轮多数决策准确率 | 68.00% | 82.22% | +14.22 pp，95% CI [10.22, 18.22] pp |
| 每题 Token | 9,950 | 12,132 | +2,182，95% CI [1,917, 2,472] |
| 每题调用次数 | 30.03 | 30.83 | +0.80，95% CI [0.66, 0.96] |

最终准确率比较采用问题级配对检验，Holm 校正后 `p = 1.23 × 10^-11`。这一结果说明，在当前主后端、固定合同和三个测试域上，过程规则与更高的资源行动率及更好的集体决策同时出现。

## 三、错误从哪里被修正

450 个配对问题的最终状态转移如下：

| No Mechanism → Static AEIC | 数量 |
|---|---:|
| 错误 → 正确 | 78 |
| 正确 → 错误 | 14 |
| 正确 → 正确 | 292 |
| 错误 → 错误 | 66 |

净纠错为 64 题。系统并非只发生单向改善，因此论文应同时报告 78 次纠错和 14 次退化，而不能只列净增益。

## 四、收益具有任务异质性

| 数据集 | 准确率变化 | 95% CI | 每净纠错新增 Token |
|---|---:|---:|---:|
| MMLU-Hard | +20.00 pp | [12.67, 28.00] pp | 15,263 |
| StrategyQA | +4.00 pp | [-1.33, 9.33] pp | 24,348 |
| TruthfulQA | +18.67 pp | [11.33, 26.00] pp | 13,498 |

可防守的解释是：知识辨析、选项排除和抗诱导任务更容易从显式证据与验证行动中获益；基线已经较强的 StrategyQA 上边际收益小。该解释与机制一致，但尚不是独立的任务属性因果分解。

## 五、三轮轨迹提供了什么证据

- MMLU-Hard：No Mechanism 从 62.00% 上升到 70.67%；Static AEIC 从第一轮 90.00% 到第三轮 91.33%。机制优势在首轮已经形成，并在后续轮次保持。
- StrategyQA：No Mechanism 为 76.00% → 73.33%，Static AEIC 为 81.33% → 77.33%。更多轮次没有带来单调改善。
- TruthfulQA：No Mechanism 为 64.00% → 59.33%，Static AEIC 为 78.67% → 78.00%。机制主要防止无约束审议中的后续退化。

因此不能写“审议轮数越多越好”。更准确的结论是：合同对信息生产方式的影响早于最终聚合；后续审议可能维持、修正或稀释首轮优势，具体取决于任务域。

## 六、AEIC 本身的边界

报告接口实验（90 个配对问题）结果：

| 报告形式 | 准确率 | 解析成功率 | 平均 Token |
|---|---:|---:|---:|
| Free Text | 72.22% | 100.00% | 95.83 |
| Generic Structure | 82.22% | 98.89% | 91.50 |
| AEIC | 85.56% | 98.89% | 150.02 |

AEIC 相对 Free Text 提升 13.33 pp（Holm `p = 0.00836`），但相对 Generic Structure 仅提升 3.33 pp（`p = 0.453`）。所以可主张 AEIC 提供统一、可核验、可进入合同结算的接口；不可主张四字段格式已经被证明具有独立准确率优势。

## 七、机制拆解排除“只是多给算力”

| 条件 | 公开合同 | 资源路径 | 高资源行动率 | 准确率 |
|---|---|---|---:|---:|
| 无合同、固定资源 | 否 | 固定 | 14.44% | 85.00% |
| 有合同、固定资源 | 是 | 固定 | 81.11% | 88.33% |
| 无合同、匹配算力 | 否 | 匹配 | 17.78% | 86.67% |
| 完整机制 | 是 | 行动驱动 | 81.11% | 91.67% |

完整机制相对匹配算力条件，高资源行动率增加 63.33 pp（`p = 2.82 × 10^-33`）；实际 Token 没有增加，反而略低且差异不显著（`p = 0.229`）。这支持“行动响应来自公开规则，而不是机械增加计算量”。准确率差值为 +5 pp，但当前只有 60 个配对问题（3 次错误转正确、0 次正确转错误，`p = 0.25`），应作为方向性证据，不做显著性强结论。

## 八、统一叙述顺序

1. 无合同的多数投票只聚合答案，无法观察 Agent 是否真正验证。
2. 公开合同把可奖励信号、成本、信息可见性和验证预算在行动前公布。
3. Agent 据此选择 Low、AEIC、Verify 或 Imitate；这些行动对应真实 Prompt、Token、调用和验证路径。
4. AEIC 报告把假设、证据、推断和结论变成统一的可审计对象。
5. 结算与信誉更新发生在报告生成之后，进而影响后续集体决策。
6. 主实验先证明“行动改变 + 结果改善”，拆解实验排除纯算力解释，接口实验限定 AEIC 的真实作用。
7. 最终结论限定在已测试的固定合同、主后端和三个任务域，不外推为一般均衡或跨模型普遍规律。

## 九、可直接使用的结论

> 在固定公开合同和已测试主后端下，过程规则使高资源行动率由 0.46% 提升至 56.93%，第三轮多数决策准确率由 68.00% 提升至 82.22%。450 个配对问题中出现 78 次纠错和 14 次退化，净纠错 64 题。匹配算力对照未复现同等行动响应，说明结果不能简单归因于额外计算量。AEIC 的主要贡献是将推理过程转化为可观察、可结算的报告接口，而非已被证明独立优于任意结构化格式。
