# 独立预算与可验证投入：本轮研究验收

## 一、结论

本轮新增了一个**可以执行、可以逐笔核对的受限资源行动博弈**：程序主体独立承担投入成本，只能选择预先登记的模型资源路径，网关自动封存原始输出，最后用可信的延迟结果结算。支付、资源账本与势函数使用同一组实际路径，没有借用旧450题的收益。

已经解决的是“怎样定义一个确实对应实现的投入子博弈”。**尚未解决的是：校准得到的均衡能否稳定泛化，以及它能否在合理对照下改善质量—成本。**本轮不是研究全部完成，也不是在线运行验收。

新增API调用 **0**。数据为此前两批均已开卷的24题；不是48道新题，也不称独立确认性测试。论文、专利、影视系统和PPT没有修改。

## 二、主体与行动到底是什么

| 项目 | 本轮定义 | 不代表什么 |
|---|---|---|
| 主体 | 三个有独立账本和决策函数的程序主体 | 自然LLM已经具有经济理性 |
| LLM | 主体购买的信息生产工具 | 能随意领取奖励、修改支付规则的玩家 |
| 行动 | K保留原始弱模型路径；U支付新增成本，采用登记的强模型路径 | 任意改提示、造答案、模仿同伴、弃交结果 |
| 行动时点 | 对一批任务提前预约固定路径，未看到该批具体问题和私有输出 | 已经完成逐请求自适应升级 |
| 输出 | 可信网关转发并封存原始工具输出，结算再次核对原文、来源哈希与扣费 | 原始工具输出一定正确；自由文本报告已经激励相容 |
| 成本 | 已记录的实际Token用量；各主体分别扣除 | 新发生了API计费；Token就是实际货币 |
| 预算 | 每题每主体3000虚拟Token预算；初始预留1000，升级预留2000 | 跨题动态财富、多个真实API账户或共享预算拍卖 |
| 结果 | 所有输出封存并聚合后，评估服务揭示标准答案并结算 | Agent可以查询答案键来解决当前问题 |

统一调用器并不妨碍模拟独立主体。关键是：主体只收到自己的收益菜单与预算，能拒绝不利建议；网关不能替它隐瞒成本，也不能把评估标签传给行动函数。当前是程序接口层面的权限隔离，不是对恶意代码的进程安全沙箱或真实P2P部署。

初始三次弱调用是本轮K/U子博弈的固定前置工作，部署成本完整计入。主体已经进入协议；**自愿加入、退出、私有成本报价没有建模**。因此，负的全流程收益不能省略，也不能用“均衡”掩盖参与约束。

## 三、支付为什么能与资源行动对应

固定三角色、两票法定人数。记：

\[
V(a,\omega)=\mathbf{1}\{\text{三角色多数结论正确}\},\qquad
V_{-i}(a_{-i},\omega)=\mathbf{1}\{\text{删除角色}i\text{后仍有两票正确}\}.
\]

角色的结算为：

\[
p_i=\lambda[V(a,\omega)-V_{-i}(a_{-i},\omega)],\qquad
u_i=p_i-c_i^{\rm initial}-c_i^{\rm upgrade}a_i.
\]

这是**正确结果上的关键票支付**，不是字段完整度、词面新颖度或“发生了一次调用”的奖励。在固定两票规则下，新增一票不能推翻另外两票的一致结论，所以差值只可能是0或1；正确时最多两票具有关键性：

\[
0\le p_i\le\lambda,\qquad\sum_i p_i\le2\lambda.
\]

三个角色全部答对时，删除任何一人仍然答对，关键票支付为0。这并非计费遗漏，而是该支付对冗余产出的处理；也因此可能出现搭便车与多均衡。

对同一任务分布，定义：

\[
\Phi(a)=\lambda\mathbb E[V(a,\omega)]-
\sum_i\mathbb E[c_i^{\rm initial}+c_i^{\rm upgrade}a_i].
\]

只要一名角色改变资源路径不会改写其他角色的请求和原始输出，删除该角色的参照项就不随其行动改变。因此：

\[
\Delta u_i=\Delta\Phi.
\]

这给出**有限资源行动阶段的精确势性质**、纯策略NE存在性，以及在真实期望收益可得时严格单边改进的有限终止。它不要求模型概率是校准的贝叶斯后验，也不要求不同角色的答案统计独立；允许共同任务造成相关错误。

但计算均衡需要收益表。本轮用校准24题估计该表，得到的是**校准经验游戏的精确NE**，不能直接升级为未知真实分布的NE。势函数最大值是该固定合同内的分配基准，不是最优激励合同，也不是Stackelberg解。

这一构造属于已有差分奖励/边际贡献思想，不把通用势性质宣称为原创定理。可参考[Wolpert等关于集体奖励设计的工作](https://arxiv.org/abs/cs/9905005)。包含努力选择、信息报告与支付的一般机制设计问题也已有[多主体信息获取研究](https://arxiv.org/abs/2307.06210)。我们的本轮目标是把适用条件与实际执行对应起来，不是重新命名已有理论。

## 四、执行与反作弊边界

执行顺序为：

1. 只用第一批校准数据形成公共收益表；披露全部λ，不从后续结果挑选奖励值。
2. 对八个K/U组合精确枚举，公布全部NE。推荐规则固定为：校准势值最大，其次新增成本较低，最后按角色编号打破平局。
3. 三个主体各自比较K/U收益和自己的预算；只有三者分别接受，协调器才提交预约。单元测试确认非最优建议会被拒绝。
4. 冻结预约和主体回执，之后才加载后续批次的评估标签。
5. 购买登记路径；原始输出自动封存。主体没有提交任意答案的接口。
6. 多数聚合后揭示结果，逐角色扣费并支付；再次核对输出、接受的结论、来源哈希、角色号和余额。

**这不是自由报告的激励相容证明。**如果允许主体免费复制同伴输出、改写结论、选择性弃交，当前行动集和证明就失效，需要另建报告博弈。网关凭证证明的是“执行了哪条资源路径”，不是“模型说的内容真实”。

## 五、真实轨迹回放结果

第一批24题校准，第二批24题回放；来源、原始响应与标签哈希保留。请求别名与实际返回模型不混同：原轨迹使用GLM弱路径与DeepSeek强路径，近期强路径实际返回`deepseek-flash`。没有把不同日期的模型版本当作严格可控的同一模型快照。

以下均包含72次固定初始弱调用：

| λ | 推荐路径：角色0/1/2 | 校准NE | 回放正确数 | 新增强调用 | 全流程Token | 回放经验单边偏离收益上界 |
|---:|---|---|---:|---:|---:|---:|
| 0 | K/K/K | 是 | 11/24 | 0 | 27,268 | 0 |
| 1,000 | K/K/K | 是 | 11/24 | 0 | 27,268 | 0 |
| 3,000 | U/U/K | 是 | 19/24 | 48 | 43,477 | 0 |
| 10,000 | U/U/K | 是 | 19/24 | 48 | 43,477 | 77.4583 |

最后一列是固定回放24题均匀经验分布上，单个角色改变其整批预约的平均虚拟收益增量；不是准确率百分点、实际账单或未知分布上的置信上界。λ=10,000时，角色2加入的收益大于新增成本，**校准均衡没有保持为回放经验均衡**。λ=3,000虽无经验单边偏离，仍距该批次全局势值最优250.125虚拟单位/题，不能把NE叫全局最优。

λ=3,000时，K/K/K与三个“两角色升级”组合均为校准NE。从全K开始的严格单边改进停在全K；公共联合推荐能选择另一个校准NE，但这属于协调器枚举，不是已经解决了去中心化均衡发现问题。

全部三个两角色升级NE在后续回放分别得到**20、21、19**正确。没有事后选21那个组合；预定的校准成本平局规则选中19的组合。这正是均衡选择与小样本泛化的风险。

### 不能省略的对照

| 对照 | 正确数 | 初始弱调用 | 强调用 | Token |
|---|---:|---:|---:|---:|
| 全K | 11/24 | 72 | 0 | 27,268 |
| 本轮推荐U/U/K | 19/24 | 72 | 48 | 43,477 |
| 全U，保留强制初始步骤 | 20/24 | 72 | 72 | 51,618 |
| 直接三强多数，跳过初始弱调用 | 20/24 | 0 | 72 | 24,350 |
| 单个强角色0 | 20/24 | 0 | 24 | 8,065 |

单强角色0并非从回放挑选：校准时三个强角色均22正确，固定按最小角色号选择0。三个强角色在校准24题上**24题结论全部一致**；后续24题仍有22题一致。更换角色提示并没有提供稳定的独立信息。成对共同错误率高于边际错误率乘积，但任务难度也会造成这一现象，不能把它当作已控制条件的独立性检验。

相同总支付上限2λ的个人结果支付对照也已计算。λ=3,000时个人支付选择K/U/U，回放20正确、48次强调用、43,553 Token；当前关键票方案少1正确，只少76 Token。λ=10,000时个人支付选择全U；关键票方案少24次强调用、少8,141 Token，但也少1正确。**目前不能宣称同时改善质量和成本，更没有超过单强模型。**

激励机制不必击败能强制所有人合作的中央最优基准；其价值可以是让自担成本的主体实现有用投入。但需要胜过合理的简单激励方案，不能只与“不给钱所以没人升级”比较。本轮尚未建立这种稳定增量。

## 六、其他检查如何服务于这一条主线

### 1. 初版个人概率评分：不是最终方法

先实现了独立预算、封存和个人适当评分，用于验证环境。它的支付可分离，与同信息中央策略相同，未形成协调优势。

在后续24题中，按角色均值升级所有61个严格概率合法槽位，得到21正确，但同样的合法性固定筛选也得到21；不是学习到的新价值。置信度分组方案43次强调用、19正确，与同角色配额的不确定性排序完全一致，固定参照为20正确。没有把这些数字移植为关键票方案的结果。

初始11个概率不合法槽位使用了保守K回退，**没有可用的投入收益估计，不能由其“零表内偏离”声称完整均衡**。这促使后续受限投入博弈只使用可追溯的实际结论和延迟结果，不再用概率字段是否合规代理有效信息。

### 2. 已知信号通道测试：机制单元测试，不是实际性能

另用精确分数运算检查了39个合成游戏、936条有向单边行动边和936条改进路径。在12个主要示例中穷举获取行动与有限信号报告映射的联合偏离；已知通道、共同先验、正确贝叶斯聚合条件下未发现均衡获利偏离。额外异质成本网格出现6个非全局最优NE，明确反驳“有势就全部最优”。

这部分不算真实题目、不继承真实模型效果，也不是最终资源协议的另一条创新线。它用于辨认假设：把一个80%可靠的同源信号复制三遍，错误地按独立通道融合，会得到98.46%的置信度，并降低预期评分；所以不能用三个同源模型输出直接套独立证据理论。

### 3. 估计不稳与成本口径

256次校准问题级Bootstrap仅用于敏感性核查。λ=3,000时，75次选择全K，80次选择U/U/K，52次选择U/K/U，其余选择单角色升级；原规则并不稳定。它不是新增独立重复实验，也不是显著性证明。

Token、虚拟信用、实际账单和延迟分开报告。若弱路径真的免费，更多Token不一定更贵；本轮另给出价格比的代数盈亏阈值，但没有假定当前收费或伪造账单。记录的调用耗时之和也不是端到端在线延迟。

## 七、本轮取舍与下一步门槛

保留**可验证资源产出＋独立预算＋延迟关键贡献结算**作为当前唯一需要检验的投入机制。个人概率评分和已知通道测试是诊断，不作为并列研究点。AEIC若继续出现，承担请求、资源来源、判断和更新的审计接口作用；本轮没有证据证明四字段不可替代。

不修改λ、不按这24题选另一个均衡、不增加字段、不将19换成事后最优的21、不追加付费调用。下一阶段若进入真实执行，必须先锁定：

- 研究范围是否接受“不可编辑的工具产出＋可信延迟结果＋已进入协议的主体”。若要研究自由语言报告、自愿进入或私有成本，当前证明不足，不能悄悄扩大。
- 是否保留三弱前置流程。直接单强模型已是强参照；没有真实异质信息或明确部署约束，继续加角色没有充分依据。
- 质量、资源和信用的比较口径；全部候选合同、均衡选择和平局规则只能由校准与预设约束决定。
- 后续来源隔离题组的动作预约必须先冻结，再采集工具输出、揭示结果；同时报告偏离收益、全部费用和简单激励对照。

**当前可防守的研究进展：投入子博弈与程序执行终于对应起来，但经验均衡泛化和应用效率还没有验收通过。**不是一开始的问题没有意义，也不是已有大幅新提升；应保留这个边界，而不是再次用一个漂亮定理替代效果。
