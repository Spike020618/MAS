# AEIC角色与最小补充实验修订

## 一、先回答核心风险

现有证据不能证明“把回答写成A、E、I、C四段就会提高准确率”，也不能证明四个字段分别不可缺少。现有主实验能够证明的是：在已测试的DeepSeek主后端上，事前公开、以AEIC报告信号结算的过程合同显著改变了Agent的资源行动；合同、执行提示和分级资源路由的联合配置同时提高了集体准确率。

因此，研究对象应稳定表述为“博弈驱动的可观测语义共识机制”，而不是“AEIC格式增益”。AEIC在其中承担可解析、可验证、可结算的报告接口角色。

## 二、现有数据支持到哪里

### 已支持

1. 在450道配对测试题、5个Agent、3轮同步审议的主配置中，高资源行动率由0.46%升至56.93%。
2. 同一联合配置下，多数决策准确率由68.00%升至82.22%，问题级配对结果为78道错转对、14道对转错，Holm校正McNemar检验为1.23×10^-11。
3. Outcome Only仅把高资源行动率提高到3.08%，准确率为67.33%；一般性的结果奖励语言不能复现过程合同的效果。
4. 奖励扫描、成本扫描、信息环境、额外Seed和Panel规模实验提供行为响应与稳健性证据。
5. 信息操纵实验表明，现有信号能够区分证据更新、社会立场、复制压力和反向证据等情形。

### 尚未支持

1. AEIC四段格式本身提高任务准确率。
2. A、E、I、C中任一字段具有独立必要性。
3. 质量提升可单独归因于信用规则、执行提示、Token预算或模型路由中的某一项。
4. 合同跨模型家族普遍有效。
5. 已求得闭式Stackelberg均衡、全局最优合同或一般激励相容机制。

## 三、为什么必须调整实验而不是丢弃旧实验

主实验中的处理同时包含三个变化：公开过程合同、动作相关执行提示、动作相关资源路径。它适合回答“整套机制是否产生行为和质量效果”，不适合回答“AEIC格式是否有效”或“哪个部件造成质量提升”。旧实验应保留为联合机制的确认性证据，并补两组小而针对性强的识别实验。

## 四、最小补充实验一：报告接口验证

### 研究问题

在模型、问题、调用次数和输出预算一致时，AEIC接口是否比自由文本和普通结构化回答更容易被稳定解析和审核？

### 三个条件

1. **Free Text**：自由分析后给出最终答案。
2. **Generic Structure**：输出“analysis”和“answer”两个通用字段。
3. **AEIC Interface**：输出A、E、I、C四个字段。

三个条件必须使用相同DeepSeek模型、相同问题、相同单次调用、相同最大Token和温度；不得绑定奖励、不同后端或额外验证调用。

### 主要终点

1. 机器解析成功率；
2. 最终立场提取准确率；
3. 证据边界识别准确率；
4. 有依据与无依据立场翻转识别率；
5. 复制行为识别率；
6. 自动判定与人工审核的一致率。

任务准确率、Token和延迟为次要终点。若AEIC不提高答案准确率、但显著提高观测和审核可靠性，仍然直接支持其“可观察语义接口”定位。

### 最小样本

先在三个数据域各抽取30题，共90题，采用问题级配对设计。机器指标全量计算；人工只需盲审分层抽样记录，并复核自动判定的分歧样本。若主要接口指标没有方向一致的改善，则停止扩大样本，并把AEIC降级为工程协议而非研究贡献。

## 五、最小补充实验二：合同与资源执行分解

### 研究问题

行动变化来自公开合同还是资源差异？质量变化来自合同诱导的行动选择还是仅来自更多计算？

### 四个条件

1. **No Contract / Fixed Resource**：无过程合同，所有Agent走固定DeepSeek资源路径。
2. **Contract / Fixed Resource**：公开过程合同，但所有动作仍走相同模型、调用次数和Token预算。
3. **No Contract / Matched Compute**：无过程合同，按Full Mechanism实际观测到的调用与Token预算进行问题级或分层匹配。
4. **Full Mechanism**：公开过程合同，声明动作绑定真实资源路径。

### 识别关系

- 条件2减条件1：在资源固定时，公开合同对行动声明和报告行为的影响；
- 条件4减条件2：动作绑定资源路径的增量作用；
- 条件4减条件3：在计算量相近时，合同引导的资源配置是否优于机械增加计算；
- 条件3减条件1：单纯增加计算的质量收益。

### 最小样本与停止规则

先在分域增益最大的MMLU-Hard和TruthfulQA各运行30题，共60个配对问题；三个Agent、一轮、固定DeepSeek后端。先验证运行逻辑、行动率差异和计算匹配，再决定是否扩至每域50题和三轮。若固定资源下合同不改变行动或报告行为，则不再运行奖励×成本网格；若Matched Compute已经解释全部质量差异，则将质量结论明确归因于资源增加，而把机制贡献限定为资源行动的可观测与调度。

## 六、现有实验的重新定位

| 证据 | 在最终叙事中的作用 |
|---|---|
| 450题主实验 | 联合机制的行为效应与质量效果 |
| Outcome Only | 排除“一般奖励提示即可”的解释 |
| 奖励/成本扫描 | 追随者对公开合同参数的经验响应 |
| 四类信息环境 | AEIC信号对不同信息行为的可操作性 |
| 字段消融 | 说明接口存在冗余，不能声称字段逐项必要 |
| Seed/Panel稳健性 | 主后端、已测范围内的稳定性 |
| GLM边界实验 | 合同语义不自动跨模型迁移 |
| 新接口实验 | 识别AEIC作为报告接口的测量价值 |
| 新分解实验 | 分离合同、算力与路由贡献 |

## 七、最终可检验的研究主张

主张一：事前公开的过程合同能够改变已实现LLM追随者的资源行动分布。

主张二：AEIC提供一组可解析、可验证、可用于信用结算的语义观测量；其价值首先是测量与治理，而不是格式本身保证正确。

主张三：在已测试主后端上，合同与动作相关资源执行的联合配置改善了集体决策；新增分解实验用于估计合同和计算资源的各自贡献。

主张四：机制有效性具有后端和任务边界，因此结论限定于观测到的经验响应，不外推为一般均衡或普适激励语言。

## 八、执行顺序

1. 冻结旧结果，不重跑、不覆盖；
2. 完成报告接口实验的代码、干跑与90题小样本；
3. 人工仅进行盲审和分歧复核；
4. 完成四条件分解实验的代码、干跑与60题小样本；
5. 依据预设停止规则决定是否扩样；
6. 只有前两组实验通过识别门槛后，才运行奖励×成本网格和经验合同选择。
