# 博弈可行性小样本诊断

目标：区分明确收益表的算术选择能力与自然语言合同下的自主响应，识别当前收益规则的问题；不证明均衡，不用本试验选择正式合同。

冻结设置：三个数据集各取开发集第一题，两个既有人格，四种执行行动；每个行动一次，Verify额外修订一次。统一DeepSeek Chat，温度0，独立信息，无同伴信息。执行后用当前静态结算器计算三份合同下的收益：奖励/成本分别0.05/1、0.2/1.5、0.5/0.5。Agent分别在合同提示下自主选择、在明确净收益表下选择。共30次执行及36次选择，即66次API调用（正常无错误情形）。

记录：原始提示与响应、提示哈希、模型别名、Token、调用耗时、合同参数、逐行动收益、选择行动及诊断后悔值。已有成功调用支持恢复；任何API错误停止，不自动改合同或无限重试。

判据：明确收益表选择正确而合同选择违背最佳响应，说明算术能力不等于合同机制有效；两者都差时先解决指令/决策理解；两者均正确也只说明小样本可行，仍须建立真实资源权益、可核验贡献、收益估计及独立测试。任意显著负结果如实保留。

限制：每个行动只有一次结果，不能当作期望收益准确估计；自主选择未必持有事后收益表信息，所以诊断后悔值不等于严格事前理性检验。独立环境下Imitate没有真实同伴可用。只读模型别名，不能证明服务端权重版本固定。现有收益中严格支配的上界判据比该单次收益估计更强，应同时解释。
