# 新颖性复查

本轮搜索发现，重设计中多个基础想法已有直接相关工作，不能仅以新系统组合宣称新机制。

| 文献 | 已覆盖内容 | 对我们设计的约束 |
|---|---|---|
| [Adaptive-RAG，NAACL 2024](https://aclanthology.org/2024.naacl-long.389/) | 学习式选择检索策略 | 不是首次让策略决定是否/如何检索 |
| [MMOA-RAG，2025预印本](https://arxiv.org/abs/2501.15228) | 将RAG多个模块作为合作学习主体 | 不能把共同F1奖励、多Agent联合优化当独有机制 |
| [MHGPO，ACL 2026](https://aclanthology.org/2026.acl-long.1399/) | 多Agent搜索系统的组相对策略优化 | 必须比较现有学习式协调，而非只对照不学习Prompt |
| [CASI，2026-10-14预印本](https://arxiv.org/abs/2610.20293) | 固定取证快照、集合干预与信用分配 | 与当前子集反事实设计直接相近，不能直接称为原创 |

CASI的具体应用是广告搜索及拍卖回放，不等于我们的开放QA环境，也不能将作者指标当我们的正确率证据。共同点在信用构造与快照控制；是否有足够方法差异，仍需逐项对照，不能仅凭换任务宣布新颖性。

## 本轮决定

继续完成已经锁定的开放取证开发屏，因为它回答信息行动是否有真实作用，而不是验证某个已经声称原创的算法。不将该屏或标准反事实学习命名为新论文成果，不据此启动正式大训练。

新颖性候选必须落到具体尚未解决的问题，例如有限预算下哪些反事实评估值得做、如何估计不可靠credit并控制更新风险；这些目前只是问题，不是已经发明的方法。后续若要选择其中一个，需先证明它不是已有方法的直接重述，并以相同评估预算设置强基线。

以上为原始论文/发表页面核查，没有复现作者实验，没有对其定理与代码作完整审计，也不宣称穷尽全部相关研究。

## 补充对照：不能省略普通顺序取证

[IRCoT，ACL 2023](https://aclanthology.org/2023.acl-long.557/)已经研究边推导边检索：后续查询依赖先前返回资料，而不是在最开始猜完所有查询。因此“原问题查一次，再按返回内容查一次”的路径应视为已有强单Agent基线，不能改称新的博弈算法。本轮只实现有限两次检索参照，没有逐项复现IRCoT原实验。

[C3，2026-10-07的v4](https://arxiv.org/abs/2603.06859v4)当前题名为The Trace Is the State: Exact Credit Assignment for LLM Agent Teams，已讨论回到共享轨迹中的决策点、替换消息并执行后续过程；[CCPO，2026-06-11的v5](https://arxiv.org/abs/2603.21563v5)讨论面向合作推理的反事实及验证器锚定信用。二者都是预印本，本轮只核查原始页面、摘要及C3官方仓库说明，未复现其训练。不能以“实际运行反事实”或“用验证器奖励”几个词宣布新颖性。

[MuSiQue，TACL 2022](https://aclanthology.org/2022.tacl-1.31/)针对多跳捷径设计；[FRAMES，NAACL 2025](https://aclanthology.org/2025.naacl-long.243/)联合评价事实、检索和推导。它们是后续环境比较参考，本小时没有下载、选题或运行，不能为了寻找正结果立即换任务。
