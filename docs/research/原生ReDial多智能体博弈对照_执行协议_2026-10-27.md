# 原生 ReDial 多智能体博弈对照：执行协议

状态：跨日于2026-10-28完成32例。最终结果位于 native_consensus_v3；[完整结果与判断](原生ReDial多智能体博弈对照_结果与判断_2026-10-27.md)。下文最初版本和修订记录均保留，不能将旧字段合同当最终执行入口。

本轮依用户“进行”运行，承接已完成的原生基准。固定同一组 32 段验证前缀、40 个推荐目标、100 候选，未新增测试集调用。该验证样本已有单模型和检索成绩，因此这是开发实验，不是未知确认集。生成只读输入和父批预测，全部方法输出封存后评分入口才加载本轮标签。

## 对照与预算

全部使用 Qwen Flash 固定版本、温度零，每次排序输出上限 512 tokens，局部复查输出上限 384。主对照上限每例六次逻辑调用，不强称相同 token 或相同实际费用：

- 单模型六步：保存的原始预测，加五次只看自身上一轮结果的复核；没有其他 Agent 的报告。
- 独立六次生成：三个公共初始处理视角，再加三个不看其他报告的独立处理视角，确定性 Borda 读出。
- 固定交流：三个公共初始排序，固定选择最靠近第十名边界的三对互不重叠候选，由非原作者复查。
- 博弈交流：三个公共初始排序，从至多六个互不重叠的有分歧边界疑点中，由三个软件 Agent 分别选择一项非自身疑点或不参与，最多三次复查。

另保留独立三次生成汇总，作为较低成本参考；它不是六次预算对照。原始单模型一次、热门和检索结果作为同样本背景。相同调用上限不能保证 token 精确相等，实际用量和费用必须分列。

原始单模型一次的每例结果和失败均原样复用，不重新花费调用。公共初始排序三次仅采集一次，所有多 Agent 分支使用相同初始状态。单模型分支不复用其他两个 Agent 的生成材料。

所有 Agent 允许读同一份当前前缀、100 候选 ID 与片名、训练检索先验顺序。处理视角不同，数据权限相同。当前没有额外历史例子或新增检索材料，所以本轮检验的是同材料处理与交流，不能宣称验证了异质私有信息融合。

## 排序与疑点

每个 Agent 输出十个不重复候选。对名次 r=0..9 赋分 (10-r)/55，其余为零；取各 Agent 平均分，共同读出排序，同分按训练检索顺序。

交流边界取共同排序前十与第十一至二十名之间的候选对。固定方式按到第十名边界的距离选三对。自适应方式仅保留至少一名 Agent 对方向有异议的候选对；优先值为：

`priority(a,b) = (max_i gap_i - min_i gap_i) / (abs(mean_i gap_i) + 0.005)`，其中 `gap_i=s_i(a)-s_i(b)`。

每个候选最多出现在一个本轮疑点，避免同一分值被多个基于旧状态的复查覆盖。原作者是最支持当前共同方向的 Agent；复查者不能复查自己的目标。

## 执行的博弈

玩家 i 的动作是 abstain 或选择一个非自身疑点 q。公开值 `v_q` 是上述 priority 除以本例最大 priority。成本为冻结请求长度和输出上限的代理：

`c_iq = 0.1 * (UTF8_message_upper / 64000 + max_output / 4096)`。

令 `V(a)` 为所有被选择的不同疑点值之和，玩家效用为：

`u_i(a) = V(a) - V(a without i) - c_i,a_i`，不参与效用零。

势函数 `Phi(a)=V(a)-sum_i c_i,a_i`。运行异步严格最佳响应，逐次检查势增量等于玩家效用增量，最后枚举全部单边偏离；同时精确枚举中央最优代理分配并记录差距。所有目标、成本、分配、均衡轨迹在对应 API 请求发出前落盘。

这是真实执行的软件控制有限博弈，不是 LLM 自发效用、真实用户偏好博弈或准确率均衡。标准边际贡献构造不是新理论；如果与中央最优代理分配等价，则不能宣称博弈求解本身有优化优势。

## 局部更新与正确性边界

复查输出已有的 preferred ID 和一至三个来源 ID，运行时附着原始文本。当前用户表达只能引用当前 Seeker 原文；推荐者表达没有该权限。只有候选片名，不允许编造演员、情节等属性。

复查选择若不同于目标原作者方向，交换原作者向量中该对候选的两个分值。其余分值严格保留，再用同一 Borda 规则汇总。它是软预测更新，不是语义真实性认证，也不声称片名足以验证偏好。

格式、引用或前置排序失败时保留原始响应。主结果将该方法该例计零；另报告保留上一状态继续服务的诊断结果，不能把它冒充成功纠错。所有方法保留相同总分母，并补充双方有效样本的新增/损害。

## 数据、采集与分析

输出：`experiments/results/native_consensus_v1/`。主程序 `experiments/paired_deliberation/native_consensus_experiment.py`；博弈实现复用 `review_allocation_game.py`；来源作用域复用 `scoped_evidence.py`。提交执行前全仓 894 项测试通过。

最多两条采集线程，物理发起至少间隔三秒；新增调用上限 600、配置标价预算上限两元，按回执实际汇总，未知请求保留 intent，不自动重发。该上限包括预留，未要求花满。共享前置生成只支付一次；每个方法逻辑成本应包含其使用的全部初始生成，不能用摊薄成本与单模型比较。

主指标单目标 Recall/NDCG/MRR @1,10,50；主对照为 @10。所有目标来自作者原生下一轮推荐影片，非真实用户喜欢标签。报告总分母、有效数、引用拒绝数、实际更新数、净新增命中、模型费用、博弈残差、中央代理差距。区间按原始对话聚类重抽样，仅作小样本探索，不作多重比较后的确认性结论。

候选未覆盖的目标仍计零，不能只报入池样本。32 段的覆盖上限是 40%；本轮不能解决候选检索漏失。@50 涉及原始十项选择以外的检索/公共尾部，不是全影片空间 LLM 直接排序。
