# 同状态核查价值与资料互补：固定诊断协议

状态：代码与无API检查完成，真实调用由用户执行。它优先于扩大v3六方法实验；不修改v3冻结实现或旧结果。

## 要回答的问题

1. 在同一个初始决策、同一目标主张、同一核查者和同一请求格式下，选择不同资料是否会产生可重复的质量差异？
2. 预先计算的预计收益能否选中比均匀选资料更好的动作？
3. 两份资料同时使用是否出现单独使用未出现的增益，这种现象是否超过模型重复波动与失败解释？

该诊断不是博弈收益实验。即使存在动作价值与资料互补，也只能说明后续协调有可能有意义，不能证明当前博弈已经识别了它们。

## 固定样本与调用

从v3的diagnostic输入中，按固定hash顺序各取4道QA、4道推荐，共8题；不读答案、不按初始错误与否筛选、不替换失败题。该批消费这些开发题的额外结果，之后不能称它们未被查看的正式测试。

每题先运行v3相同的3份初始资料分工，并生成、保存同一个共同初始状态。目标主张按问题词项匹配与ID确定，核查者固定为0，预先保存5份未读资料各自的预计收益与特征。默认预设贡献估计；有独立训练v3模型时可指定模型，检查训练原题组不重叠。

对每题固定16种资料集合：空集1种，单份5种，两份组合10种。每种重复2次；每个分支从同一状态深拷贝启动，一次请求同时看到该集合，不承接其他分支更新。共3+16×2=35次逻辑调用/题，最多280次物理尝试，配置费用上限5元；实际用量及未知计费另报。两个题目并发，单题分支按固定顺序执行。

初始完整请求若与已有v3预设比较批完全一致，可复用完整回执。所有分支按精确请求持久化，未知请求不自动补发。replicate_id只是独立请求的记账区分，不要求模型改变答案；若后端输出确定，两次可能完全一致，不冒称独立随机试验。

空集分支也允许基于初始资料重新思考和局部修正，用于控制再次调用本身的收益。单份与两份分支都只有一次核查调用、相同输出上限；两份分支输入更长，资料数与tokens并不相同，不能把联合收益说成同成本收益。

## 核查输出与限制

所有分支采用相同诊断输出：固定目标、联合判断support/refute/unclear、逐条原文引文、资料作用support/refute/context、联合理由，以及局部补丁。没有具体答案示例。单个资料可只贡献部分前提，因此不强迫“两份联合支持”被写成“每份单独充分支持”。

非放弃修改必须引用全部新增资料，且每条引用都有逐字原文；QA只能设置原生答案选项，推荐只能交换一个Top10内ID与一个外部原生候选，其他位置保持。不支持修改可以明确放弃。结构有效和引文存在不认证推理真实。

诊断格式与v3生产核查合同不完全相同，目的是避免单份和联合分支使用不同格式造成混淆。结果不直接等于v3运行器效果；将v3学得模型应用于诊断属于跨核查格式的选择迁移，不能冒充同分布校准。原生标签只评价最终答案/命中，不评价自然语言主张是否正确。

## 指标与解释

令Q_r(S)为第r次响应在资料集合S下的QA正确性或推荐Recall@10。

- 单份增量：Delta_r(A)=Q_r(A)-Q_r(empty)。每个动作两次平均后，比较预计收益最高动作与5个动作均匀选择的平均质量变化。
- 联合增量：Q_r(AB)-Q_r(empty)。
- 相对单份优势：Q_r(AB)-max(Q_r(A),Q_r(B))。
- 交互项：I_r(A,B)=Q_r(AB)-Q_r(A)-Q_r(B)+Q_r(empty)。正交互只是候选，不等于语义互补成立。
- 强一些的候选模式：两次响应中均为联合比空集好、两个单份都不比空集好，而且同一比较四个分支全部合同有效。不能用单份工程失败制造“联合才有效”。
- 重复波动：同一单份动作两次Q的绝对差，及空集两次变化。
- 选择可迁移性：用第一次实际响应挑选动作，只在第二次响应评价；对照第二次的均匀选择，避免在同一次响应上选最优再宣称可实现收益。

每题所有来源、预测、分支和比较保留，不只展示最佳例子。失败维持原决策，计入执行质量与失败率；只有全部有效的比较才可进入上述互补候选计数。无初始主张题保留，不补题。推荐按题Recall计算诊断，不和QA混成一个总分。

8题、两次重复、10种组合的多重搜索很容易产生偶然现象；不据此宣称显著、因果互补、学界先进或博弈有效。目标仅覆盖一个固定疑点；没有信号不能直接外推所有疑点。初始正确率很高会限制纠错空间，必须读初始质量和空集对照后解释。

## 事先确定的后续判断

1. 先看工程失败。若结果主要由无效输出组成，不能讨论动作价值；保留原始响应定位合同，不用扩大数据掩盖。
2. 若资料动作均无改善，或差异与重复波动相当，暂不继续调博弈；检查证据供给/任务是否存在可利用信息，不能把回顾性最优当可预测收益。
3. 若动作有可重复差异，但预计选择不如均匀，优先改贡献估计，暂不换博弈求解器。
4. 若存在重复一致的联合才有效候选，读取实际引文和推理，再考虑能表达互补的收益模型；当前v3的固定递减公式不能因此自动被认可。
5. 即使预计选择有增量，仍需在后续相同选择能力的单Agent、简单选择、中央与博弈之间比较，不能将资料选择收益全部归因于博弈。

本批不自动触发新一轮、扩大样本、训练模型或修改方案。完整输出后根据这些诊断再作判断。

## 用户运行

无API准备已经在experiments/results/action_value_panel_v1完成。运行：

```bash
bash scripts/run_action_value_panel.sh experiments/results/action_value_panel_v1 --run
```

相同命令可恢复中断并复用完整分支；不得改输入、重复数或模型后继续写同一命名空间。默认不加--run只准备，无网络调用。当前没有真实回执，不提供虚构效果。

主报告：root/report.md；逐题/逐对交互与重复数据：root/summary.json；基线：baselines；预动作预测：predictions；分支：branches；完整题级案例：cases；原始请求/回执：slots。所有题级案例封存后才读取标签。

已有独立训练的v3模型时，无须重新付费采集，可对同一批封存响应重新评价其选择能力：

```bash
bash scripts/run_action_value_panel.sh experiments/results/action_value_panel_v1 --prepare \
  --rescore-model experiments/results/protocol_v3_frozen/model/model.joblib \
  --rescore-output experiments/results/action_value_panel_v1_learned_rescore
```

此命令要求面板已完整封存、模型存在且训练题组不重叠，零API调用，不修改原面板预测和结果。模型尚不存在时不要为了运行此命令先启动整套大实验；默认先检验预设估计与实际动作空间。

实现：experiments/action_value_panel.py，scripts/run_action_value_panel.sh。9项新测试及23项v3测试共32项通过；覆盖同状态隔离、16种组合、重复、正向联合的合成用例、失败不冒充互补、逐字引文、恢复不重发、封存后标签、模型离线重评。合成用例仅验证统计与接口，不作为真实效果证据。
