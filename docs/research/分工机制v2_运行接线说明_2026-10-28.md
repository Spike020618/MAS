# 协议v2运行接线

本次无API。旧输出不可复用为新资料动作结果。当前只支持固定Qwen Flash，不宣称跨后端控制已经实现。

1. 新资料分区（无API）：

```bash
.venv-native-benchmark/bin/python -m experiments.prepare_disjoint_acquisition --inputs experiments/results/e2_action_acquisition_160_live_v1/inputs.json --output experiments/results/disjoint_tasks_v2
```

2. 采集前检查（无API）；通过后加`--run`，新物理上限300、配置费用上限3元：

```bash
.venv-native-benchmark/bin/python -m experiments.acquire_disjoint_actions --inputs experiments/results/disjoint_tasks_v2/tasks.json --output experiments/results/disjoint_actions_v2
```

3. 同一分区预承诺，先prepare-only（无API）；采集完整seal后改为`--fit`：

```bash
.venv-native-benchmark/bin/python -m experiments.fit_disjoint_contribution --run-root experiments/results/disjoint_actions_v2 --output experiments/results/disjoint_model_v2 --prepare-only
```

4. 新六方法真实运行（默认准备，无API，加`--run`执行）：

```bash
bash scripts/run_protocol_v2.sh experiments/results/disjoint_tasks_v2/tasks.json experiments/results/protocol_v2_heuristic --estimator heuristic
```

五核心方法外，默认保留`score_greedy`：按分数选前三的强对照，而不是用较弱的随机固定替代它。fixed按稳定hash，与收益无关；中央和博弈共享同目标/资源约束，不要求博弈胜中央。动作只使用semantic_doubts匹配到的真实claim目标，无匹配source不伪造依赖，问题与目标实际进入review payload。

训练模型后换新输出目录、`--estimator learned --model experiments/results/disjoint_model_v2/model.joblib`。运行器默认拒绝训练/校准任务重用；正式测试必须提供仅diagnostic任务包，或真正新任务和隔离资料，不能对整个fit/cal/diag全集宣称测试。`--allow-development-reuse`仅限明示开发回归。净收益模型已包含损害，v2不再重复减损害概率。

缺来源任务保留no_permitted_source且不进入动作收益拟合。来源库过少/组件连通导致预分区不可用应保留诊断，补真实资料，不退回随机题组拆分。CLI不包含自动代跑或监控。旧runner及旧结果均未改。

```bash
bash scripts/run_protocol_v2_pipeline.sh experiments/results/protocol_v2_frozen --prepare

bash scripts/run_protocol_v2_pipeline.sh experiments/results/protocol_v2_frozen --run
```

第二条包含真实付费调用，串行完成三个阶段，不需要逐条手动接线。当前160题输入的固定分区中，diagnostic为37题；两种收益估计都只在这37题比较，fit/calibration不混入效果测试。默认采集上限300请求/3元；每个比较批另有自己的运行预算，并非整个流水线总费用上限。错误会停止流水线，不自动更换样本或方案。重复执行使用同一目录由各阶段校验和已保存记录处理；无法安全恢复时明确报错，不自动覆写。

来源处理只排除不能跨问题迁移的当前对话、模型对当前题的预测与当前用户事实，共565条来源记录；保留外部文档、训练侧资料和静态知识。共享公开背景本身不等于泄漏，本协议属于更严格的资料隔离检验，不能把它包装成唯一正确的数据划分。
