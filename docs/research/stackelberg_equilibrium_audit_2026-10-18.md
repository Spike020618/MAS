# Stackelberg均衡求解审计

## 已完成的合同搜索

开发网格27个任务域—合同条件、1,350条问题级记录通过完整性、路由、Schema和Trace校验。奖励0.2、成本1.5在三组事先登记的Leader效用权重下均获得最高开发集样本效用。其准确率91.33%，中心合同90.67%，差异仅1道题；目前没有独立测试证明质量提升。

这证明的是观测策略下的开发集合同择优。此前将这一优化直接称为“经验Stackelberg均衡”的口径不成立，本审计更正该说法。

## Follower最佳响应审计

当前静态合同的信用为：

`credit = reward_scale * (complete_aeic + consistency)`

两个信号均在[0,1]内，所以奖励0.2时信用上界0.4。成本倍率1.5时：

| 行动 | 净效用上界 |
|---|---:|
| Low | 0.4 |
| AEIC | -1.1 |
| Verify | -2.6 |
| Imitate | 0.1 |

Low成本为0，所有信用系数非负，故Low净效用下界0。AEIC和Verify被Low严格支配，无须虚构反事实生成结果即可建立这一必要条件检验。

所选合同2,250个Agent-round中，999次选择了这些严格被支配的高资源行动，占44.4%。平均单步后悔值下界0.4891个合同信用单位。该结果拒绝“观测策略是当前单步收益下的精确最佳响应”。它不等于完整反事实收益估计，也不证明存在已建模的跨任务继续价值。

若声称Agent因长期信誉而接受单步亏损，必须明确跨任务总收益、信誉的未来实际权益、折扣因子和动态最优响应；当前不能事后添加这种解释。

## 已实现的求解工具

- `experiments/mechanism/audit_equilibrium.py`：输出支配行动和后悔值下界。
- `experiments/mechanism/solve_finite_stackelberg.py`：对完整有限收益表先枚举Follower最佳响应，再枚举Leader最优纯承诺；分别计算乐观与悲观平局约定。
- 求解器拒绝缺少反事实行动收益的输入；单纯选择日志不能替代完整收益表。
- 8项相关测试通过，包括最佳响应先于Leader择优、平局规则、缺失收益拒绝和负效用上界审计。

求解器目前支持一个Follower。多Agent只有在明确建模为联合Follower且允许协调时才能直接使用该解释；独立自利Agent应求Follower子博弈均衡。现有独立信息设置可能允许收益可分离，但必须验证报告评分和结算是否确实不存在策略相互依赖。

## 均衡目标的后续实现顺序

1. 冻结新的单步或动态博弈定义，明确信用的实际用途与资源预算，不在观测结果后任意增加潜在效用。
2. 在训练/开发题的同一局部状态下，分别执行四种行动，获取反事实收益与资源成本；区分强制行动的测量实验和Agent自主行动实验。
3. 改进过程合同：当前完整性及合法Yes/No立场对所有行动均可能给满分，不能证明独立信息生产的边际价值；若采用核验奖励，必须有实际核验信号及支出记录。
4. 根据完整收益表求最佳响应与最优合同，并报告Follower偏离收益、Leader偏离收益、估计不确定性及平局约定。
5. 冻结合同后验证Agent自主响应是否接近求解结果；若自然语言Agent仍有显著后悔值，结果是理论均衡与实际行为的偏差。使用显式效用优化控制器可实现所定义有限博弈的理性响应，但必须标明决策由控制器执行，不能冒充LLM自发理性。
6. 所选合同的既定留出测试矩阵已生成。由于当前均衡必要条件未通过，暂不启动该批1,350条付费准确率实验；先解决收益定义与最佳响应，再冻结与新机制匹配的验证矩阵。
