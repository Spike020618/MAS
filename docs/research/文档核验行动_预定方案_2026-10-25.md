# 文档核验行动：采集前锁定方案

## 唯一目的

验证真实原文访问是否使局部核验优于普通审阅；本阶段不加支付、不求均衡、不宣称 AEIC 字段贡献。先确认行动价值，再考虑协调。本文件在本批任何模型调用之前保存，采集协议锁定其 SHA256。

## 数据

QuALITY 官方 v1.0.1 ZIP，使用有标签的 htmlstripped.dev；官方 test 无公开标签，不将 dev 冒称 test。20 个不同 article_id 且文档内容哈希不同，每篇按预定输入哈希选一道题。不筛 hard、不按错误或分歧挑题。人工难度、writer_label、验证与速度标注全部剥离，gold_label 单独保存。

来源 https://github.com/nyu-mll/quality/blob/main/data/v1.0.1/QuALITY.v1.0.1.zip 。记录 ZIP 哈希、源记录数、每文档许可与原始 URL。对现有请求响应日志做精确渲染题干及 JSON 转义题干排除；不是语义或预训练未见保证。

## 四臂、共享与实际调用

- full：同一模型直接看全部原文回答，1 次。
- fixed：固定词面检索，查询为题干与全部选项，读取最多六个窗口直接回答，1 次。
- review2：共享 full 初始报告，再看全文普通复查两次，总路径 3 次。
- local：共享 full 初始报告，根据初始判断定位一项关键前提并生成查询，执行真实词面检索，再看返回原文窗口核验与作答，总路径 3 次。

每题物理调用为 full、fixed、review1、review2、plan、local，共 6 次；20 题上限 120 次。review2 与 local 各在初始报告之后增加两次调用；输入 Token 不同，不能称同算力。所有方法成本完整计入所依赖的 full 初始调用，不把共享当免费。没有三 Agent 投票或人为错误观点。

local 取回的是同一原始文档的局部材料，不是第二份独立来源，也不是模型从未看过原文的全新事实来源。新调用只见查询所选窗口；不能夸大独立性。

检索：220 词窗口、110 词滑动，按文档内词面匹配排序，抑制超过一半重叠，最多六窗。窗口保存字符起止、原文哈希、实际查询。查询完全不读 gold、人工证据或官方解释。规划非法时按事先规则回退固定公开查询，另记失败。

## 模型与解析

固定 DeepSeek 实际返回模型 deepseek-flash 及已观察 fingerprint，非思考模式 temperature=0.2；最终输出上限 1000、规划上限 400 Token。返回身份变化或 HTTP/未知传输失败停止，不自动重试、不静默换模型、不调用 Qwen。

所有答案允许 A/B/C/D/abstain，必须为完整 JSON；可接受额外元数据，不把 harmless type 字段制造为机制错误。截断或缺失必要字段记弃答。引用逐条只检查给定窗口内的字面匹配；不把字面匹配当蕴含、更不据引用格式改判答案正确性。原始文本和失败都保留，不猜答案。

## 评价与门槛

全部输出、读出先封存，再读取本阶段标签。主比较 local vs review2；full 与 fixed 为必要强参照。报告配对正确纠正/错误翻转、Exact McNemar、三比较 Holm 校正，完整正确数、弃答、非法计划/答案、引用匹配、Token/调用/HTTP 累加时间。并发下 HTTP 累加不等于端到端时间。

这20题只是行动价值开发筛查，不是独立确认或对整个领域的结论。不在本批结果上调查询、窗口、Prompt 或成本后宣称通过。

若 local 对普通审阅没有净纠正，不据此进入博弈扩展。若 local 有净纠正，还必须检查其相对全文直答及固定取证的额外收益和总成本；小样本正向仍只允许锁定新题组验证，不宣布机制成功。若主要只是固定取证有用，应先采用简单方案，不强行制造博弈必要性。

## 执行与保护

每题独立五臂中间状态和六次请求日志，最多三题并发；调用前写入尝试，完整响应先于解析落盘；不确定请求不自动重发。成功日志重跑复用，输入或代码变化拒绝。旧实验、标签、冻结代码、论文、专利、系统和 PPT 不改。

运行：`python -m experiments.mechanism.run_document_verification run`。
源数据准备：`python -m experiments.mechanism.run_document_verification prepare`。
