# 研究主线、论文与实验的一页入口

本目录保留“预算约束下基于证据贡献博弈的多智能体共识机制研究”主线。它是方法型论文与推进基本盘，不以历史失败分析替代研究目标。

核心论证链：**有值得协调的信息 → 能预测并选择有效核查 → 有依据的修订进入共同状态 → 与同信息同选择能力的强控制比较 → 证明收益属于哪些机制。**

论文预期贡献是一个完整机制：证据状态与可靠修订、状态相关贡献估计、预算博弈协调共同决策。三个部分不另拆研究方向，也不把已有组件名字当创新。
