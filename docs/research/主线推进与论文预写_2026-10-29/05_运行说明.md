# 集合证据价值博弈：统一运行说明

版本：evidence-set-consensus-release-2，2026-10-29。代码位于 experiments/consensus_mechanism；不覆盖旧批次。当前默认开发输出 experiments/results/consensus_mechanism_set_v2r1；论文数据固定在consensus_mechanism_paper_v2，见06文件。

## 一条命令执行

在项目目录执行：

```bash
bash scripts/run_consensus_mechanism.sh experiments/results/consensus_mechanism_paper_v2 all --run --max-cny 20
```

论文目录依次执行：4题接口检查 → 123题匹配训练与拟合 → 400题九方法主比较 → 原生推荐强基线评分 → 同64题固定子集动作价值诊断 → 同子集五项消融 → 四种追加预算 → 三种干扰 → GLM迁移 → 180条公开证据关系 → 458题HotpotQA比较 → 汇总。

默认主模型Qwen Flash，迁移模型GLM Flash；模型版本与价格配置由现有review_model_profiles.py记录。读取.env.local，不打印密钥。公开数据已下载并准备，不需要人工标注。没有--run不会发模型请求。

旧开发目录真实probe已尝试28次，27返回、1未知；已知配置费用约0.02611335元，接口门未通过，未进入全量训练。新论文目录尚未调用模型。训练拟合的是小型收益预测器，不是微调Qwen/GLM。

```bash
bash scripts/run_consensus_mechanism.sh experiments/results/consensus_mechanism_set_v2 check --fetch-data
bash scripts/run_consensus_mechanism.sh experiments/results/consensus_mechanism_set_v2 train --run

bash scripts/run_consensus_mechanism.sh experiments/results/consensus_mechanism_set_v2 report
```

其他阶段：ablations、budget、stress、transfer、semantic。模型依赖未完成时会报错，不会静默换成启发式。主比较及后续方法实际都经过Runtime真实API接口。

默认每个采集子批费用上限5元，不是整套总额5元。开发套件共有14个计费子批，含HotpotQA的论文套件15个，配置上限分别合计70/75元；这不是预计实际花费。可显式传--max-cny 1降低各子批上限；达到上限的请求会保留失败记录，不能把预算截断批次当全部有效运行。物理回执physical_summary.json与平台账单核对，未知请求不当0费用。

37题开发套件的无缓存请求上界约6600次；论文套件上界约3.4万次，取决于合法行动数量；成功回执的精确复用会减少实际请求。已有全局约3秒提交间隔，仅提交间隔就可能接近数小时；论文全套仅提交间隔的保守上界约28小时，实际复用会缩短；完整流程应预留一至两天，不能按37题×单次延迟估计。--limit只截取评价任务，不缩小123题训练；改变limit或预算需新目录，不能在已冻结阶段原地改参数。

## 输入与方法

- 训练123题：原fit/calibration分组保留，单份模型与二阶交互模型分别拟合，校准只调均值偏差。
- 开发比较37题：QA17、推荐20，存在历史开发暴露；所有方法同题、同原生候选和资料权限。
- 公开核查180条：原始Climate-FEVER固定提交版本，每个claim按hash选一条人工标注证据；三态证据关系子任务，不是原生claim级榜单成绩。
- 九方法：同选择器强单Agent、独立分工汇总、固定核查、集合边际贪心、中央同目标枚举、博弈、独立采样投票、Self-Refine、普通多Agent讨论。
- 五项消融：去交互、去集合去重、去状态重规划、禁用联合操作、允许自由重写。
- 主预算为3次初始+最多2次追加调用，最多2份追加资料；联合两份用一次调用。Token、来源读取、费用分别记录，并非强行相同实际token。

扩大为200 QA+200推荐须在采集前选择独立目录并锁定，不根据37题效果临时挑样本：

```bash
bash scripts/run_consensus_mechanism.sh experiments/results/consensus_mechanism_set_v2_400 prepare --expand-test 200
bash scripts/run_consensus_mechanism.sh experiments/results/consensus_mechanism_set_v2_400 all --run --fetch-data
```

新任务排除可观察历史原生题ID/会话，不宣称排除语义重复或模型预训练接触。若候选数量或资料不足会明确报错，不自动缩量或偷偷补真目标。第二条使用已落盘的400题，不重新抽样。

## 验收与恢复

结果在report.md、report.json、metrics.csv；主比较main/summary.json，选择诊断value/value_summary.json，语义semantic/summary.json。逐题cases、原始slots、意图intent、源码和模型快照保留。

中断后重跑同一条命令；相同输入/代码/模型才可续跑。已完成case直接复用；成功请求按精确请求复用；未知完成不自动补发。遇到源码漂移，保留旧目录并使用新输出目录，不能删plan或intent绕过检查。

probe按接口有效率检查，不按答对率或正收益选题；失败会停止训练后续。全部主结果保留失败和原始分母。观察到相同分数时，配对修正/损害、实际Token及求解开销仍输出，不把均衡证书当任务成绩。
