# v5.1实验协议调整与离线验收

本轮把上一份[修订说明](v5小批校准与实验修订_2026-10-26.md)落实到可执行代码，新增模型调用0。研究主线及E1→E2→E3顺序保留；本轮实现E2/E3修订和扩展校准，不声称真实推荐效果已完成验证。

## 校准从24条扩到84条

新增七类受控语义题：当前偏好、时间适用性、主体归属、否定、部分支持、证据冲突、提及与观看/喜欢区分。每类12条，支持/反驳/不足各28条，共28个上下文组。输入只包含不透明ID、主张、证据；标签、类别、上下文组放在独立评分文件中，ID排序不按标签分组。

发送前固定门槛为：总准确率≥90%、每类召回≥80%、每个语义类别准确率≥75%、错误支持为0、无无效核验输出。所有题均为合成的证据相对校准，既不是84个真实对话人工标签，也不是论文确认性测试；同一上下文派生的三条判断不可视为完全独立。

## E2公平对照

所有方法从相同的三角色初始报告出发，使用相同原始证据与候选池、共同输出指令、相同预算上限。

| 方法 | 核验反馈 | 更新方式 |
|---|---|---|
| independent | 无 | 初始报告直接聚合，作为低成本参照 |
| central_matched | 与拟议方法相同 | 单中心控制器，连续审阅历史与当前全局状态，允许整份报告更新 |
| self_matched | 与拟议方法相同 | 各角色只审自己的初始主张，允许整份本角色报告更新 |
| peer_matched | 与拟议方法相同 | 同伴读取冻结初始主张，允许整份目标角色报告更新 |
| verified_scoped | 同一批核验反馈 | 同伴提出逐主张修改，状态机约束撤销/替换/未决 |

主比较固定为拟议方法对普通同伴、拟议方法对中心控制器。中心控制器拥有相同核验反馈、原始信息和完整审阅历史，不能靠遮蔽中心Agent信息构造多Agent优势。主同伴比较保持冻结初始主张，中心控制器是具有连续状态的强替代方案，两者不冒称同拓扑。

核验反馈绑定原始claim hash；更换主张后不能沿用旧核验结论。凡允许核验的方法都可在相同预算上限内核验新主张，不给拟议方法独占额外工具权限。新增核验与替换复核照常计费入账。

共享初始生成和共享核验物理上只执行一次，但每条使用它们的方法都计入完整逻辑成本；去核验和不交互路径不读取相应反馈，也不分摊其逻辑成本。账本拒绝重复计入同一共享槽位。预算相同是上限相同，实际Token与调用数并不被伪装成完全相等，仍须报告质量—成本曲线。

## E3真实运行时消融

1. `no_runtime_verifier`：不读取共享核验，不调用语义核验器，按模型提议执行保留/撤销/替换/未决，但保持单主张结构合同。未经核验的主张保持unverified，不标为证实。
2. `no_scope_constraint`：直接复用普通同伴`peer_matched`的整报告更新结果。它是同一可执行条件的别名，不重复付费，不当作新增独立样本。
3. `force_binary`：使用相同核验结果，但将证据不足强制映射为模型选择的保留或撤销，记录`forced_from_insufficient`。这是用于检验弃判必要性的干预，不是生产安全策略。

删除事后评分器不再列为方法消融；早期路由/证据内容实验不混入当前最小核心消融组。未来增加这些因素必须另冻结协议。

## 离线验收与入口

回归覆盖：中心与拟议方法收到相同反馈；共享初始与核验完整入账；去核验路径确实无反馈/无语义调用；强制二元确实改变未决状态；整报告修改和逐主张拒绝越界有实质区别；别名不增加调用；输入不含标签；即便总体准确率超过98%，出现1次错误支持仍不通过校准门。

入口为`python3 -m experiments.paired_deliberation.run_v51 --output <新目录>`，默认仅prepare。统一入口`run_experiment.py`也默认v51；旧v5及v4仅显式选择版本复现。

执行阶段为：

- `--phase calibration --execute-authorized`：执行84条扩展校准并评分；标签不进入模型请求。
- `--phase comparison --execute-authorized`：仅在扩展校准通过、计划/输入哈希和返回模型一致时执行前三例工程对照。
- 没有自动pilot入口。真实推荐增益、独立事后语义评价与正式样本量仍须另冻结。

已准备的计划目录为`experiments/results/paired_deliberation_v51_preflight_r2/`。本轮未运行84条真实模型校准或三例真实对照；机器回归是工程验收，不作为方法有效性证据。
