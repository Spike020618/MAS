# 中期汇报收尾清单

## 当前目标

短期目标不是继续扩展项目，而是完成中期汇报。汇报口径为：研究主线、实验工程、大规模实验资产和影视应用原型已经基本完成；剩余工作属于因果识别、应用评测与论文统一的收尾工作。

## 中期汇报前必须完成

- [x] 重构汇报叙事：博弈驱动的多智能体语义共识机制为主线，影视搜推为应用验证。
- [x] 形成与参考答辩稿一致的 HTML 演示稿结构、主题、键盘交互和演讲者备注。
- [ ] 核对汇报中的数字、实验名称和图表标题与冻结数据完全一致。
- [ ] 准备 8—10 分钟口头版，并完成至少两次计时演练。
- [ ] 录制或截取一段影视系统的稳定演示，避免现场依赖 API 状态。
- [ ] 准备老师可能追问的三类问题：创新点、因果混杂、系统完成度。
- [ ] 冻结中期汇报版本，只修事实和表达问题，不新增研究方向。

## 中期汇报后的必要收尾

### P0：直接影响核心结论

- [ ] 完成固定后端、固定 token、固定验证预算的 E-Control 实验，识别公开合同本身的行动效应。
- [ ] 根据 E-Control 结果确定最终论文可以使用的因果措辞。
- [ ] 统一实验、理论和文档中的术语，明确区分“合同效应”和“观察行动后的资源分配效应”。

### P1：补齐应用验证

- [ ] 将已下载的 MovieLens 25M 与 ReDial 处理为可复现的影视目录和评测集。
- [ ] 完成 E-Movie 正式离线评测，对比字段检索、单 Agent 和多 Agent 共识。
- [ ] 把 Agent 选择的 action 接入真实模型、验证与通信预算，并完成机制结算。
- [ ] 固化系统 Demo、trace 样例、失败降级样例和结果图。

### P2：论文与答辩交付

- [ ] 重写问题定义与贡献，保持开题时的博弈主线。
- [ ] 将拓扑定位为信息结构和成本控制变量，而不是独立主线。
- [ ] 补齐实验图、表、统计检验、威胁与局限性。
- [ ] 完成论文全文一致性检查和最终答辩 PPT。

## 明确暂不开展

- 不扩展新的应用场景或数据集。
- 不再新增一条“拓扑优化”研究主线。
- 不进行与核心结论无直接关系的大规模功能开发。
- 不重跑已经冻结且完整的八套实验；只有发现数据或实现错误时才回滚重跑。
