# 顺序取证的停止与继续：40题开发屏

## 问题和边界

只回答：不同请求的合适停止时点是否不同，是否存在值得学习分配的质量—成本空间。不训练博弈，不宣称自适应检索原创。本轮不验证“选哪条分支”；每一步查询按固定协议产生，若继续/停止空间成立再研究分支选择。

保留此前所有冻结产物，不修改旧报告、代码、标签或论文/系统。

## 输入和执行

固定同一HotpotQA fullwiki开发集及5233329篇BEIR语料。按输入ID的固定哈希取40题，排除仓库历史规范化题干。前20题开发、后20题确认；两组同时冻结，不按题型、难度、支持事实或答案筛选。这不是来源组隔离或正式独立测试。

S0：数据集原生、未标记的10段资料。

S1：根据问题和S0资料生成一条缺失事实查询，真实检索前2篇，合并原文。

S2：根据问题和S1资料再生成一条查询，再检索前2篇，合并原文。

查询生成只看当前实际资料，不看先前求解答案、理由、金标准或支持事实。不能将S2查询拿去独立于S1执行。原文title+text内容寻址、稳定排序、去重；每阶段40,000字节，超过则停，不筛文档或截断。

每阶段分别用同一个deepseek-flash模型的非thinking和thinking模式求解。两模式的最终提示相同，固定为先简短说明、引用、最后答案；非thinking温度0.2/输出1000，thinking去掉温度/输出4096。不同模式资源不同，分别比较，不称同等计算预算。

每题最多2个查询生成＋6个求解请求，共320次。完全相同请求在本题内部复用实际响应，不把重复生成当作取证收益。所有原始响应先写盘；未知传输状态停，禁止自动重试。模型标识与fingerprint固定；本批保守费用代理上限5美元，不是实际账单或服务商硬限额。每题保存阶段真实耗时、查询时间、调用及Token；断点复跑不覆盖原始记录。

40题全部封存后才读标签，不能看前20结果再改后20配置。输出非法按失败保留，不能修到正确为止。

## 对照和成本

固定S0/S1/S2策略：直接生成所需查询后最终求解一次。S2无需付S0/S1中间答案成本，因为查询生成不读取它们。

自适应停止策略：必须支付已观察过的中间求解。预定简单规则只有“非abstain则停止”和“资料无新增则停止”，分别报告，不能事后挑最有利规则。abstain严格按规范化输出abstain/noanswer识别，不按理由或gold改判。

每种模式分别报告全部40、开发20和确认20。开发组按EM、Token、阶段顺序选最好固定阶段，再原样用于确认组；另列确认组事后最好固定阶段，只作描述性参照。

离线oracle只作为上限：逐题事后选择停止阶段，完整支付其观察成本；用动态规划求各正确题数的最小Token，并同时记录调用数。不得把它叫可部署策略、训练结果或最终效果。另列不付观察成本的理想选择上限，明确其更不现实。

报告优化执行的固定路径Token与自适应路径Token，不能因为固定路径未付中间答案就将它人为加费。模型缓存重复输入的成本按所选路径实际需要的唯一请求计，不能将两个推理模式共享响应。

## 预定指标和继续门槛

主要质量指标为官方答案EM，F1作为必要辅助。逐题列出纠正/伤害、措辞边界和已读来源。主要描述性比较为thinking的S2对S0；补充S1对S0、S2对S1及非thinking结果。配对Exact McNemar，三个thinking比较用Holm校正；40题是开发屏，不承诺检验力。

只有确认20题中，thinking模式的“支付观察成本oracle”在不高于优化固定S2的Token预算且不高于其调用预算时，比确认组事后最好固定阶段至少多2个EM正确，并且至少2个差异是可定位事实差异而非措辞，才建议进入分配机制开发。该门槛是实际增量筛选，不是显著性检验。候选oracle没有这些事实条件，最多标记“待核查”，不能自动放行。

若不满足：保留数据和普通取证结论，不调奖励、不增字段、不启动120题训练。若满足：下一步先做非博弈控制器，再比较同反馈同预算的博弈学习；不是立即宣称新机制有效。
