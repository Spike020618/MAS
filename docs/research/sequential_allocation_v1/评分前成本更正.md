# 评分前成本更正：无需答案观察的策略

采集进行中、尚无整批评分时复查发现：冻结采集器的原分析函数将no_new_documents规则按“需要读取每阶段答案”的策略计费，但这条规则只检查新增原文数量，不必生成S0/S1中间答案。这会不必要地削弱简单策略，必须更正。

不修改冻结采集器、模型请求、任务、阈值、标签或已写日志。另存版本化分析：no_new_documents采用所选停止阶段的优化固定路径成本，即必要查询生成＋最终一次求解；abstain_only确实读取中间答案，仍采用累计观察成本。原始分析结果保留并明确标记，以更正分析作为成本解释入口。

原预定的“付观察成本oracle相对最好固定阶段”门槛不改变。但另列相同Token/调用预算内最好简单策略，防止把已经被普通规则覆盖的空间推荐为新机制。无论何种门槛通过，都不自动启动训练。

更正脚本在整批评分存在前生成带UTC时间、已封存题数和代码/说明哈希的声明；不是看了效果后修改成本或挑选规则。
