# 40题停止与继续取证：结果与取舍

## 结论

本批未达到进入分配机制训练的预定门槛。非thinking配置有顺序取证收益；thinking强参照没有净准确率收益，而且更费Token。计入观察成本的事后oracle在确认组只多1个EM正确，这唯一的正差异还是同一片名的表述变化，不是新的事实纠正。

因此停止本分支的付费扩展，不启动120题训练，不改变阈值、奖励或提示来追逐这批题。该结果不证明一切取证/博弈方向都无效，只说明当前初始资料、后端、路径及预算下，未显示足够的新增分配空间。
