# 竞争核验：实验前设计审查

状态：待用户确认；本文件不授权新模型调用。既有冻结协议、数据和结论不变。

## 1. 已做的改变与没有完成的事情

已实现：固定候选的论证提交、具体挑战、真实原文检索、看到挑战后的回应、最终判断。上一轮6篇文章、24个候选、222次调用，是角色化交互开发屏，不是策略训练或均衡求解。

结果：普通审阅及非适应性对照的平衡核验错误率为22.22%，交互为25.00%；交互严格唯一接受读出仅1/6正确、5/6弃答。六个独立来源组不足以判定普遍优劣，但足以阻止直接扩样、宣称成功。

尚未完成：交互独立贡献、博弈学习增量、真实核验质量目标与策略收益的有效连接。此前“采集前锁定”只是程序冻结，不等于已经完成用户设计确认。

## 2. 研究假设收缩

只检验一个近期问题：在相同原文访问和成本记录条件下，针对候选的具体挑战，是否比普通复查更能发现决定性的支持缺口并改善最终选项判断？

将其拆为两个可否证环节：

1. 挑战驱动的检索是否优于题干与所有选项的固定检索？
2. 在完全相同证据下，针对挑战的回应是否优于普通重述？

两环节都没有增量时，不引入支付或学习来重新包装。即使有增量，也只是协议有效性的证据，不能直接认定博弈贡献。

## 3. 优先做零调用复核

复用上一轮已保存材料，不改标签、不改原始输出：

- 对三项改变最终判断的候选，逐条对应原论证、挑战、查询窗口、回应与最终理由。
- 区分新增可追溯事实、纠正推导、重述原文、无证据强化表达；来源字面匹配不等于语义支持。
- 检查窗口是否遗漏限定词、否定、相邻段落；记录而不按这些题定制检索规则。
- 检查最终判断是否回答“最佳选项”，而不是“选项有部分依据”。
- 由原始记录确定是否存在可跨题执行的接口缺陷。无法从记录裁决的，明确保留未知，不把解释当因果结果。

交付：差异案例表与下一轮是否值得做的判断。此分析属于开卷诊断，不作为独立测试。

## 4. 若诊断支持继续：统一权限的候选协议

所有角色使用同一后端和固定采样配置；所有最终核验者均可见全文，检索窗口只是带位置的辅助索引，不以隐藏全文制造任务。全文直接问答始终保留。

对每题四个候选全部执行，角色不知道官方标签：

1. 作者提交固定候选的论证，并明确一个决定性前提；允许承认不支持，不强迫捍卫错误。
2. 挑战者依据全文与论证提出一个可定位的质疑和查询。不得访问其他臂输出或标签。
3. 词面工具返回原文窗口、位置和哈希；不返回正确性提示。
4. 作者在相同全文权限下，分别独立产生普通重述和针对性回应。重述不见挑战；两分支不互看。
5. 最终核验者读取对应材料，输出接受、拒绝或未决，以及决定性依据。不能改候选身份。

分支和消息权限必须在请求构建器测试中逐项验证，而不是只在提示词中声明。

## 5. 必须保留的对照

| 路径 | 作用 | 最终核验信息 |
|---|---|---|
| 全文直接问答 | 最便宜强基线 | 题目、所有选项、全文 |
| 普通审阅 | 检查复杂交互是否有必要 | 原论证、全文 |
| 固定查询辅助审阅 | 分离检索本身的价值 | 原论证、全文、固定查询窗口 |
| 挑战查询辅助审阅 | 分离针对性证据定位 | 原论证、全文、挑战、挑战查询窗口 |
| 挑战＋普通重述 | 回应对照 | 上项材料、预先生成的重述 |
| 挑战＋针对性回应 | 待检验协议 | 上项材料、针对性回应 |

后两路径的全文、挑战和窗口一致，改变回应内容；独立随机核验仍会引入采样噪声。单次结果不作逐案例因果断言。多步普通审阅应按最终拟定路径调用数补齐为预算参照，不能只与一次审阅比较。

不声称相同调用数就是等计算量；分别报告Token、调用、HTTP耗时及端到端耗时。共享前缀按每条部署路径计入，实际采集总成本另列，避免重复或漏记。

## 6. 主要判断与扩展门

候选级主指标：按问题宏平均的平衡核验错误率，未决和非法计错。应用级指标：四候选严格唯一接受的正确率、弃答率；全文直接问答单列。候选数不是独立样本数，按文章分组分析。

不能只改善候选分类，却恶化最终问答而称为成功。不得把增加弃答、引用数量、字段完整率或说服力当准确率增益。

继续条件：在未用来源组中，相对普通预算参照和非针对性对照出现值得进一步验证的质量—成本改善，且轨迹没有信息泄漏、格式差或读出规则伪增益。小屏只决定继续与否，不承担统计显著性的正式结论。

停止条件：无增量；新增误收抵消纠正；收益只来自更大上下文或更多调用；接口修复即可由简单基线复现。停止后保留负结果，不在同批题上调提示、阈值或奖励再当独立验证。

## 7. 博弈在什么位置进入

只有上述实际行动通过后，才设计有限策略学习：作者选择提交/修订策略，挑战者选择核查策略，核验者选择判断规则。训练阶段可以用正确性反馈，测试阶段冻结全部策略、禁止读标签。

目标先对应可观察的错误接受、错误拒绝及成本，再检查是否存在合理的策略冲突。不能默认“作者追求接受”就等于“挑战者追求真相”；也不能奖励挑战数量或纯拒绝率。

必要对照是固定策略、随机策略、同数据同预算的非博弈优化器。若博弈学习不能超过它们，贡献只能是核验协议或优化结果，不能是博弈的独立优势。有限经验策略表上的偏离检验不自动外推为真实任务总体均衡，更不宣称全局最优。
