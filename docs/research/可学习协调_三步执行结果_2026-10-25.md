# 三步执行结果：实现、真实运行与结论边界

## 结论先行

本轮不再停在计划：已实现并运行固定 DeepSeek API 上的可学习生产协调，补齐固定、随机、普通优化对照，完成 12 题训练后冻结、12 题隔离测试。**没有观察到博弈的独立准确率或目标增量。** 实现与实验执行完成，不代表整个研究目标完成。

严格 Consensus Game 全文似然复现仍未完成；API 编码适配不能替代它。可学习协调是借鉴 ECON 的有限表格原型，不是 ECON 复现或其贝叶斯纳什保证。

## 一、Consensus Game 到哪里

已实现原文交叉归一化与同步 piKL，使用默认 eta=lambda=0.1、5000 次更新，分别保存末次与平均策略，补齐 G/MI/SC/D/ER-G/ER-D 读出。实现完整文本 teacher-forcing 评分接口、断点封存、代码/输入/模型内容哈希。

已用 DeepSeek 编码概率适配跑过六题：34 次调用、4,258 Token，六臂均 5/6，无额外纠正；该结果单独保留。本轮协调实验的三份初始快速报告同时提供同候选多数决策能力参照，但不是完整文本概率池上的严格原文对照。

尚未完成：原论文模型、模板、完整序列似然与作者实现数值对齐。本地模型后端尚无真实运行验收；DeepSeek 公开接口没有发现所需的输入完整似然评分功能。因此不能宣称原论文复现失败，也不能用本轮负结果否定原论文。

## 二、这次真正实现的学习与博弈

每题先产生三份独立快速判断，其中一份固定，两个程序主体各自选择保留报告（0）或真实调用 thinking-enabled 路径（1）。最终仍为三票多数。所有方法使用同一个 DeepSeek 后端、同题与同候选，不用换模型制造差异。

训练 12、测试 12，StrategyQA/MMLU/TruthfulQA 各四题/阶段；在固定来源池按输入哈希筛选，做历史精确题干和 ID 排除。不按错题或分歧挑题，不保证语义与预训练未见。

程序主体的定义收益为延迟集体正确奖励减自己的升级 Token 成本。系数事前锁定为每 Token 1/50000；它是实验成本偏好，不是实际人民币价格。经验势为集体正确率减总升级成本。训练仅拟合全局/初始一致性上下文的四行动表，测试不读取标签决策、不更新策略。

博弈控制器从 00 开始执行严格单边获利更新；集中式非博弈控制器直接优化同一训练目标。前者可计算训练经验游戏的无获利偏离状态，但不保证全局最优、真实分布均衡、私有成本激励相容或自然 LLM 的自利行为。

训练阶段四组合全部 9/12，没有集体正确率差别。因此两个学习控制器都选择 00。没有为让 Agent 升级而重新调整成本。

## 三、冻结测试结果

| 方法 | 正确数 | 实际选中路径 Token | 选中路径调用 |
|---|---:|---:|---:|
| 博弈控制器 | 10/12 | 9,827 | 36 |
| 普通集中式经验优化 | 10/12 | 9,827 | 36 |
| 固定 00，不升级 | 10/12 | 9,827 | 36 |
| 固定 01 | 10/12 | 17,796 | 48 |
| 固定 10 | 10/12 | 17,527 | 48 |
| 固定 11，全部升级 | 10/12 | 25,496 | 60 |
| 四组合均匀随机期望 | 10/12 | 17,661.5 | 48 |
| 同升级次数随机期望 | 10/12 | 9,827 | 36 |

随机是固定潜在输出池的解析期望，不是额外独立重复。各策略均计三个共同初始调用，再计选择的升级；原始采集为覆盖训练与所有对照，共 **120 次物理调用、48,234 Token**，与单个策略成本不同。HTTP 耗时之和 224.9744 秒，因三路并发不等于端到端时间。

博弈与普通优化在 12 题上选择完全相同。相对所有固定组合，正确性配对纠正/伤害均为 0，检验不能据此证明一般等效。观察到的成本节约来自“不做无收益升级”，固定 00 同样做到，不能称为博弈必要性或独有优势。

## 四、深查发现什么

1. 训练和测试各 11/12 初始一致，上下文很少出现分歧；稀疏状态按事先规则回退全局训练表，没有依据测试调阈值。
2. 测试有一题升级提供了初始三份报告都没有的正确答案，但只有一个升级角色给对，多数决策仍错。因此存在局部信息增量，但没有形成集体结果增量。
3. 在已观察的全部 24 题上，四行动组合的正确/错误状态逐题相同，二元正确收益的交互项均为零。在这个已实现菜单和读出上，经验收益退化成不变正确收益减各自成本；没有证据表明形成了需要博弈协调才能利用的收益耦合。不是全局“不可能”定理。
4. 完整披露单报告能力控制：测试 fast0/fast1/fast2 为 9/10/10，think1/think2 为 10/11。后者是事后全角色审计，不从测试选择“最强角色”作为已部署策略。它反而提醒：当前多 Agent 协调并未超过便宜的单报告路径，不能只拿全升级作为昂贵对照制造优势。

## 五、验收与取舍

执行链路已覆盖：真实行动、训练反馈、冻结策略、在线测试决策先于升级、后采反事实路径不回流、标签后读、固定/随机/普通优化基线、实际 Token 与延迟、恢复时零新调用、原始证据哈希。

本轮没有形成新有效机制，不扩到 300 题，不在这 24 题上继续改奖励、换成本或挑子集。既有正向历史结果保留，不能与当前经验游戏理论拼接。当前最具体的瓶颈是“少数正确信息如何被可靠识别并影响结果”，但本轮没有证明新的识别规则有效，也不据此承诺另一个一定成功的方向。
