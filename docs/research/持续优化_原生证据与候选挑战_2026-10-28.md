# 持续优化：原生证据、候选挑战和预算协调

用户授权并行优化与实验。本轮围绕“互补材料处理→具体疑点交流→有依据局部更新→预算协调→公共排序”，不以增加同样讨论次数代替提高信息和可达范围。

- 另64段，Top10命中14/83提高到17/83；候选覆盖32/83提高到42/83。
- 全验证集的聚类区间显示上述检索差值约7.91个百分点，探索性95%区间[6.75,9.08]。这属于检索改进，不计为多Agent增益；验证集已有项目探索历史。

融合的组成、28配置搜索、训练内选参轨迹与公式见[训练侧检索增强](原生ReDial训练侧检索增强_2026-10-28.md)，主产物为 native_retrieval_inner_v1。

## 算法修改

原方法交换两个Agent分值，无法恢复初始共同遗漏。新方法在公共100项排序中选择a（当前Top10待挑战项）和b（整个候选池中候选），可将b直接交换进入a的位置。其余所有位置保持；默认保护前3。选择来源必须是本次实际提供且与新候选相关联的训练、历史或KG实质来源，不能只拿标题身份卡支持晋升。

公开疑点价值结合训练邻居支持、实体关联、检索先验和初始分歧。三个Agent各选一个非自身疑点或不参加；博弈与中央枚举共享完全相同的价值、成本和请求表。中央对照真实调用同类模型，不只报告代理最优值。实现及公式见[候选挑战设计](原生候选挑战_算法与无标签验收_2026-10-28.md)。

无标签离线审计用三个完全相同的初始检索前十：32例192个共同遗漏候选均有合法进入前十的动作，保护前缀与无关位置不变；都有非零训练支持。它证明可达性，不是预测效果。

## 本轮模型对照

统一Qwen Flash、相同数据访问权限和六调用上限：

1. 单模型一次及六步：从一开始可读全部材料，只看自身历史预测。
2. 独立三次和六次：前三分别处理电影属性与两个历史材料子集；附加三次可读合并材料，不看他人结果。
3. 三个初始报告后，由中央分配至多三次候选挑战。
4. 相同目标与成本，由预算博弈分配至多三次候选挑战。

所有条件访问的总材料相同，不把异质Agent额外材料单独奖励给多Agent。完全相同请求按请求哈希重放，原始响应只支付一次；逻辑成本逐条件计入。四条采集线程，物理发起间隔至少1.5秒；未知超时不自动补发。

主策略一致：模型排序不合法时保留其上次状态或公共检索先验；候选更新不合法时保留公共排序。另报告所有调用有效率。该策略不同于前批整路径失败计零，因此前后批的模型增量必须在同批对照下判断，不能直接把回退造成的分数差当模型进步。

## 顺序与故障保留

先8段旧开发对话，输入选择与先前相同，不按新结果挑选；再使用新64段中预先固定的32段迁移样本。新对话与旧32段无原始对话重叠，但整个valid有探索历史，不称独立确认集。模型生成只读inputs，全部方法封存后才加载本批labels。

第一批新排序入口漏写JSON字样，被Qwen JSON对象模式拒绝；该批 native_open_evidence_screen_v1 保留为工程失败，不能算排序模型效果。修复为明确JSON指令，并新增调用前检查；另立 screen_v2，未改写旧响应。修复后首例12个排序11个有效，才放行剩余样本。

数据体统一压缩为统计数值表和每片三条原生KG边，完整卡保留审计。单例排序保守输入上界约1.96万–2.21万，低于6.4万阈值。挑战仅提供当前/历史原文和候选对相关逐项来源，更新器只接受本次offered来源集合。
