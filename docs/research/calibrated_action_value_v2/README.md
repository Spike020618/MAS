# 贡献预测与停止条件修订：自然主张实测

研究主线保持多智能体博弈共识。本修订集中解决“有用行动未进入协调”的预测缺口，先以真实标注主张诊断，再回接自然推荐；不把构造域正结果替代自然评价。

## 审计依据

旧贡献拟合：186条单份收益184条零、2条正；93条交互92条零、1条负。另有26条动作或控制无效的观察，旧拟合未排除无效行。既有构造诊断中，固定或随机实际纠错而旧估计的博弈选择停止，表明应分别检查执行有效、预计损害、预计纠正和停止，而非只调博弈求解器。该诊断不能外推为自然主批的确诊。

## 标签与模型

固定当前状态s，动作a后的真实决策质量为Q_after，未行动质量为Q_before。有效动作的标签Z=Q_after-Q_before，取-1、0、1。执行失败保留event和fallback，但Z=None，不当作真实零效果训练；有效性另学。

估计p_v(s,a)=P(valid|s,a)以及p_+(s,a)、p_-(s,a)=P(Z=+1/-1|valid,s,a)。进入分配器的预计增量：

\[
\widehat g(s,a)=\widehat p_v(s,a)\,[\widehat p_+(s,a)-\widehat p_-(s,a)].
\]

净效用减去lambda*预计人民币成本，lambda预设0.1（质量单位/元），不是把人民币直接等同准确率。旧模型与新模型在本比较中用同一成本权重、同样最多2次核查和2包资料。采用带L2正则的多项Logistic回归；按校准集NLL选择固定候选温度{0.5,1,2,4}，不在测试成绩上选阈值、调权重。只有一个观察类别时采用该类常量分布，不人为给所有动作抬高正收益。

特征由声明的当前状态与资料计算：主张词面覆盖、最大/最小/平均覆盖、联合覆盖互补、资料间重复、长度、数字、否定词、当前答案类型、已见/新材料量、状态版本。不得使用gold、原生ID、分区、裁决或题型标签。是轻量可解释估计器，不宣称实现语义真实性认证。文本统计由服务器预处理，所有选择方法同权限；材料预算指发送给LLM的包数，非服务器从未访问原文。

Q_empty为同状态不读材料核查，额外报告Q_after-Q_empty；它不与总决策增量标签混用。总方法评价加入同调用上限的只反思分支，避免把重新思考的收益全部归为证据贡献。

## 数据与隔离

使用本地固定版本Climate-FEVER原始1535条公开人工标注主张；排除先前semantic180出现的claim ID，按与标签无关的claim hash选32条：fit16、calibration4、test12。选题不看标签难度或提升结果。

每条保留原始全部证据，按证据ID hash交错分成A/B两包，AB为完整原始资料。评价使用原数据claim_label，而非把一条passage的标签冒充联合资料标签。起点是hash确定的临时三分类答案；因此这是原生文本/原生标签下的受控初始状态实验，不是原始排行榜分数，不代表真实初始模型的错误分布。

同一claim ID不跨分区。共享维基来源允许存在，不能称来源完全隔离或跨主题泛化。训练只读取train.labels.private.json；测试标签文件在评价响应封存后读取。收集与选择过程不发标签给LLM。自然推荐迁移仍需ReDial材料、原生排序局部操作以及对应分组训练，不能直接套用本三分类适配器就称通用迁移成功。

## 执行与对照

关系判断任务中，原生答案与目标主张的support/refute/unclear关系一一对应。模型只返回decision、span_ids、简短理由claim；程序确定性地生成目标核验关系、局部set_answer和keep/revise，仍执行引用与本地更新校验。所有方法共享这套适配，不让模型重复填写同义枚举。此为任务适配，不是自动改正答案。缺乏证据只能选择声明的不确定答案；不能为实质支持/反驳补丁编造引用。

训练侧20题分别收集empty/A/B/AB四个同状态真实响应，合计80请求。工程检查前4题至少13/16有效；传输未知不重发，原始回执保留。旧v1因同义字段、截断和一次未知完成而停在4题；该记录保留。v2改用紧凑关系适配器，新协议不伪装为旧请求重试。

独立测试比较：旧贡献+博弈、新贡献+博弈、新贡献+贪心、新贡献+中央、总体先验均值+博弈、固定、随机、只反思。初次预测和选择在任何测试采集前冻结；分配器只得到预测，不得读取测试效果。所选动作真正进入请求；适配器请求不携带预计收益、方法名或算法提示。实际状态更新后重新估计，扣除实际调用与资料预算。

本版本贡献模型按单一核查者数据拟合，三名逻辑成员共享该模型，执行器也使用统一核查者上下文。它用于验证贡献预测对行动选择的影响，不证明异质私有Agent的协作优势、去中心化部署或博弈独有收益。中央同目标精确解作参照，不预设博弈胜过它。

## 复现、费用与下一步

```bash
bash scripts/run_calibrated_action_value.sh --prepare
bash scripts/run_calibrated_action_value.sh --run
bash scripts/run_calibrated_action_value.sh --report
```

--prepare不联网；当前v2已由Codex启动all，不要重复启动。运行可中断，按同命令继续已完成分支；unknown按耐久纪律保留。默认每主阶段硬上限1元，Qwen Flash关闭思考；测试动作四分支面板额外0.3元上限，精确复用测试已有成功响应。总上限不等于估计实际费用。

主测试后额外采集测试同状态四分支，验证初始动作价值MAE、漏掉正动作数量和真实组合收益。这个面板在模型和策略结果封存后进行，不能反馈给同批拟合。汇总提供逐主张配对差、bootstrap区间和精确符号检验；12题是诊断规模，不宣称已达到论文主实验功效。

若新估计优于旧但与总体均值相当，下一步提高语义/状态区分能力；若新估计改善选材且各优化器同效，把进展归给贡献预测，再扩充确有协调竞争的自然动作空间；若联合/异质信息有额外价值，再验证博弈对预算效率和分散协调的贡献。任何路径都不改成“负结果复盘”作为用户未授权的论文定位。

相关方法依据：[Learning to Defer, ICML 2020](https://proceedings.mlr.press/v119/mozannar20b.html)把委托决策与成本敏感学习联系起来；[Active Feature Acquisition综述, IJCAI 2026](https://ijcai.org/proceedings/2026/860)讨论信息获取、预期效用与停止。此处借鉴其成本/错误联合评价思路，概率分解和特征模型本身不作为足够的新颖性声明。

## 已完成的本轮验收（后续以本节与最终报告为准）

首轮12条留出：历史模型5/12，新概率估计7/12，同训练数据同特征Ridge9/12；固定与随机9/12。概率复杂度本身没有优势，因此保留Ridge强对照。

随后只用原fit16/cal4，拟合一个带L2的收益方向偏置b：p_b(z|s,a)正比于p(z|s,a)*exp(b*z)，按校准主张等权最小化预计增量的MSE＋0.05b²；b限制[-2,2]。它校准的是预计决策收益方向，不只调整分类置信度。b=0.64568，校准损失0.94468→0.79259。验证使用另外24条新主张，不回调原12条。

状态条件贡献修正：对固定原始状态s0定义学习集合价值F_s0(S)，每步分配使用F_s0(S∪a)-F_s0(S)，其中S是已经读取的资料；成本只扣新增动作，历史成本为沉没成本。由此防止重规划把B当作从未读过A时的独立价值。此修订对Ridge和概率估计器均适用。

24条新主张最终结果：历史模型8/24且不行动；未校正概率10/24、13调用；校准概率12/24、28调用；同数据Ridge12/24、30调用；两种条件贡献模型均12/24、24调用。固定13/24、27调用；随机13/24、38调用；单Agent一次读完整资料13/24、24调用；独立两次核查后汇总13/24、48调用。贪心、中央、博弈在条件贡献下同效。新模型解决停滞并减少重复核查，但没有超过强单Agent或固定基线。

原fresh evaluation存在方法别名共用new_game执行器槽位的碰撞。修复采用NamespacedAPI，将公共方法名纳入逻辑槽位、保持物理请求字节不变。旧evaluation保留，evaluation_v2为权威回放结果，133份成功回执复用、0新增付费请求，unknown不补发。不是改模型或按效果筛选案例。

最终报告：experiments/results/calibrated_action_value_v3/final_report/report.md；机器记录同目录summary.json。独立复算所有方法、两组状态条件对照、单Agent/独立汇总，并对照原生数据源SHA和claim_label核验24条标签。69项相关回归通过。本轮配置已知费用约0.08705元，未知完成的潜在计费另保留记录。

重要实验条件：本轮只有两个材料包且预算允许一次读全，所以它是贡献估计与状态更新的组件诊断，不是严格材料稀缺的完整博弈实验。各逻辑成员共享价值向量，也不证明异质核查者协作优势。下一步应保持同一研究方向，使用超过预算的原生证据候选、真正成员条件的核查收益、多疑点动作竞争，并在ReDial原生排序协议复核；不再用这批作为算法唯一优越性的证据。

推荐机会的完整训练侧审计：60条中20条有池内Top10外目标（19条初始零命中、1条部分命中）；此前截取的6条候选不能当作总数。来源experiments/results/recommendation_headroom_audit_v1/summary.json。此为机械空间，不等于证据充分。

复现：--run完成第一轮；--followup完成新24条、命名空间安全回放、两种估计器的状态条件对照和完整基线面板；--report汇总。所有已完成生成都会跳过，不重发未知请求。代码加载概率模型时使用calibrated_value_report.load_value_model以兼容最初python -m产生的__main__类路径。
