# 通用机制实验：用户命令行运行

本次仅实现脚本、mock和单元测试，没有代跑API。旧v6/E2进程状态需用户查看，勿重复启动同目录。此方案测机制跨信息环境的稳健性，不保证所有资料都有答案，不将新模型拟合作为机制有效证明。

## 1. 准备四种信息环境（不调用模型）

```bash
cd /Users/spike/code/MAS
.venv-native-benchmark/bin/python -m experiments.prepare_mechanism_environments \
  --inputs experiments/results/evidence_consensus_e1_tasks_v1/tasks.json \
  --output experiments/results/mechanism_environment_suite_v1
```

baseline是同一原资料的统一1000字符版本，不保证充分；missing删除部分来源，不保证删中关键事实；redundant在同一source内重复正文，不增独立证据数，2002字符不被2500上限截掉；distractor加入其他任务的真实材料并降低当前事实权限，不保证语义完全无关/错误。未构造伪造“真值冲突”或gold充分材料。四条件原native group不变，各变体必须同split，不能当四倍独立样本。

## 2. 先运行启发式机制基准

只准备、检查计划（无模型调用）：

```bash
bash scripts/run_environment_matrix.sh \
  experiments/results/mechanism_environment_suite_v1 \
  experiments/results/mechanism_environment_runs_heuristic_v1 \
  --estimator heuristic
```

确认后相同命令增加`--run`，顺序运行四环境、每环境五方法：

```bash
bash scripts/run_environment_matrix.sh \
  experiments/results/mechanism_environment_suite_v1 \
  experiments/results/mechanism_environment_runs_heuristic_v1 \
  --estimator heuristic --run
```

只想先测一个环境，可使用：

```bash
bash scripts/run_mechanism_suite.sh \
  experiments/results/mechanism_environment_suite_v1/baseline/tasks.json \
  experiments/results/mechanism_environment_single_check_v1 \
  --estimator heuristic --smoke --run
```

smoke与完整运行必须不同输出目录，输入数及方法参数不可原目录改变。当前脚本固定Qwen Flash及每批1000物理调用/配置5CNY上限，实际消耗按回执记录；四环境是四个有限批次，不代表总共5元。缺额度/超界会失败保留，不自动换贵模型。未知请求不重发。

## 3. 训练来源隔离的贡献估计器

E2动作采集未完成时只能prepare，不能fit：

```bash
.venv-native-benchmark/bin/python -m experiments.fit_transfer_contribution \
  --run-root experiments/results/e2_action_acquisition_160_live_v1 \
  --output experiments/results/transfer_source_heldout_v1 --prepare-only
```

完整generation seal出现后，同参数改为`--fit`：

```bash
.venv-native-benchmark/bin/python -m experiments.fit_transfer_contribution \
  --run-root experiments/results/e2_action_acquisition_160_live_v1 \
  --output experiments/results/transfer_source_heldout_v1 --fit
```

按原题/对话与来源正文内容连通分组。组件不足3个或共用资料桥接造成无法隔离时明确报错；这是数据不足，不删检查/不随机拆题蒙混过去，需要独立资料或不同来源集合。特征不包含题ID、sourceID、URL、标题或正文文本。QA无效/弃权baseline不冒充动作收益。模型输出`model.joblib`，与旧E2模型schema不同。

跨任务方向：上述两条命令都增加`--held-kind qa`或`--held-kind rec`，同时换输出目录。来源跨任务桥接可导致协议拒绝，需如实报告。

## 4. 学得收益实际驱动分配

模型成功拟合后：

```bash
bash scripts/run_environment_matrix.sh \
  experiments/results/mechanism_environment_suite_v1 \
  experiments/results/mechanism_environment_runs_learned_v1 \
  --estimator learned \
  --model experiments/results/transfer_source_heldout_v1/model.joblib --run
```

本版预测实际进入中央/博弈收益矩阵，不再只记录score；单体/独立/固定策略保持相应控制。收益系数、误改风险系数均须看结果前设定，不择优报告。运行器默认拒绝拟合/校准任务重用，只有开发回归才允许显式`--allow-development-reuse`，并标记非泛化。

注意：运行器只完成原题组重用检查，尚未证明新评价来源与训练来源互不重叠；不能据此直接声称source-heldout泛化。训练脚本的来源隔离诊断和真实运行跨来源评价是不同证据。正式跨来源评估还需独立来源集合。

## 5. 收益估计误差敏感性

```bash
bash scripts/run_environment_matrix.sh \
  experiments/results/mechanism_environment_suite_v1 \
  experiments/results/mechanism_environment_runs_perturbed_s0_v1 \
  --estimator perturbed \
  --model experiments/results/transfer_source_heldout_v1/model.joblib \
  --noise-seed 0 --noise-level 0.01 --run
```

噪声档及seed应预先固定，换设置必须新输出目录；保留零噪声、多个seed和全部结果，不能只挑最好者。扰动检验代理误差稳健性，不模拟真实语义真值。

## 6. 汇总

```bash
.venv-native-benchmark/bin/python -m experiments.summarize_mechanism_environments \
  --runs-root experiments/results/mechanism_environment_runs_heuristic_v1
```

其余estimator换对应runs-root。各环境单独比较五方法质量/成本；不合并变体作独立样本，也不把资料更好导致提升算成机制收益。单环境缺结果会显示missing，不假称已完成。当前24题只作开发接线，正式泛化需要扩大独立任务、来源和模型。

最先执行1和2的prepare，无须等待训练；不要运行不存在的模型路径。若来源连通导致3报错，先保留错误及split诊断交给设计端处理，而不是绕过隔离后继续称通用。
