# 博弈机制成立性：深度调研与解决方案（2026-10-29）

任务界定（用户核心约束）：预算约束下的贡献博弈是本研究的关键一环，目标是给出使其成立的路径，而不是以负结果收尾。本文按"实验特性 → 学界方法映射 → 机制重设计 → 分阶段验证路径"给出方案；每条设计原则都锚定一个已封存实验。诚实前提先说：**方案使博弈优势可检验，不保证成立**——但当前全部负结果的正确读法不是"博弈无效"，而是"博弈成立所需的输入条件从未被满足过"。

## 1. 机制学诊断：博弈要成立，五个前提必须同时为真

| 前提 | 含义 | 当前证据状态 |
|---|---|---|
| **P1 非空且异质的动作流** | 存在有真实价值方差的核查/读取动作可供分配 | ✗主批：自拟主张自证，0接受更新。**✓v3组件诊断：自然主张+受控机会下7–8/24纠正**——链路本身能通 |
| **P2 材料稀缺** | 预算 < 检查全部提议的成本，分配必须取舍 | ✗v3明示"两包资料预算内可全读"；E5预算扫描在零吞吐下恒等。**从未在非空流+稀缺下测过** |
| **P3 交互/联合价值** | 存在联合行动价值>单份之和的任务域（超加性） | ✗E0/E2：单跳任务交互项≈0（正确退化）。HotpotQA（官方双文档必要支持）=交互富集域，正在采集 |
| **P4 异质核查者** | 核查者成本-质量档案不同，分配=任务-人员匹配问题 | ✓校准数据已存在（Flash应换入6/Plus 9/GLM 3，误换2/1/2），但从未用于分配 |
| **P5 独立验证结构** | 验证者不暴露于当前决策的理由（避免确认偏置） | ✗扰动实验：rec感知层自证（错述当前排名）；QA判断层能检测。**CoVe式分离未实现** |

**结论：博弈从未在 P1–P5 同时成立的 regime 里被测试过。** 这有数学支撑：无稀缺且收益次模（边际递减）时，贪心近似最优（Golovin–Krause 自适应次模理论，本仓库引文[8]）——博弈没有优势空间。我们的恒等结果（6.7、6.8节）恰是该定理的实证复现。**同理可推出博弈的取胜空间：P2稀缺 × P3超加性 × P4异质**——离开这个交集，任何协调机制都不该赢，赢了也解释不了。

## 2. 学界方法映射：每个失效层都有对应解法

| 失效层（我们的证据） | 学界对策 | 核心机制 | 与我们证据的契合点 |
|---|---|---|---|
| 自证动作空间（自拟主张只支撑当前决策） | **Chain-of-Verification**（CoVe，Dhuliawala等，2023） | 先生成草案→规划"验证问题"→**分解独立作答**（不看草案理由）→条件修订 | 我们rec感知自证=CoVe的设计动机；扰动实验QA判断层能检测矛盾=分离验证即可用 |
| 无需求触发（该查的不查，不该查的全查） | **FLARE主动检索**（Jiang等，2023）/主动学习不确定性采样 | 仅在低置信/分歧处触发外部信息获取 | E0无机会域保持正确=触发应只在机会信号处开火；排序器分歧是现成的label-free置信信号 |
| 讨论/评审无增益 | **Debate-or-Vote**（Choi等，2025，引文[1]）、**投票vs共识**（Kaesberg等，2025，引文[2]）、**self-consistency**（Wang等，2022） | 投票可解释多数"讨论"收益；独立采样+聚合是更强的多样性来源 | 我们self_consistency 0.2243批内Recall最优=同向证据；同信息评审恒等=同向 |
| 无外部反馈的自纠错失败 | **Cannot Self-Correct**（Huang等，2024，引文[6]）、**CRITIC**（Gou等，2024） | 外部工具/证据反馈是纠正的必要条件 | v3"只反思"9/24最差=同向；E1直判（有材料）F1 0.61可用 |
| 自然主张验证可行 | **FActScore式原子主张分解核查**（Min等，2023） | 分解为原子主张逐条独立核查 | v3自然主张7–8/24纠正=该范式在我们数据上成立 |
| 交互价值建模 | **Shapley-Taylor交互指数**（引文[7]）、RepoShapley（引文[9]） | 交互项只在超加性域有意义 | SetAllocator已有交互项数学，缺的只是交互富集任务域（HotpotQA） |
| 异质模型成本-质量路由 | **FrugalGPT级联**（Chen等，2023） | 按任务难度路由到不同成本/质量的模型 | 核查者校准档案=现成路由表；配合P2稀缺即成真分配问题 |
| 引文合同 | **ALCE**（引文[5]）、Sufficient Context（引文[4]） | 答案质量与引用质量分离评价 | E1合同有效率8.9%=合同应作记录不作闸门（已修，扰动v2验证） |

**综合诊断**：我们缺的不是博弈数学（SetAllocator的交互项与边际贡献效用是对的），是**博弈的上游**——动作从哪来、何时触发、谁独立验证、在什么任务域上联合价值存在。文献对这四点各有成熟解法，且每一点都和我们某一封存实验互相印证。

## 3. 机制重设计：盲区提议—需求验证—预算博弈

保留现有框架的骨架（原子主张、来源引用、版本化局部更新、边际贡献博弈、SetAllocator），重设计四个上游模块：

**M1 机会引擎（盲区提议，替换自拟主张）**
- QA：答案关键前提枚举 + 反事实挑战生成（"哪个前提若为假会翻转当前答案？"）——从问题与当前答案的依赖结构生成，不从模型自证主张池生成。
- Rec：排名挑战提议——未排入但与对话高关联的候选（检索错配信号）+ 已排入但低支持的条目；独立排序采样的分歧项。
- 可用时直接用自然主张池（v3证明该路径纠正率7–8/24）。

**M2 需求触发（FLARE式）**
- 仅在机会信号处生成提议：排序器分歧 / 独立采样分歧 / 反事实脆弱性 / 检索错配。无信号→不动作（保持，正确行为）。这使动作流**非空且价值有方差**（P1）。

**M3 独立验证（CoVe式分离）**
- 验证者看到挑战与材料，**不看到当前决策的理由**；三态直判（E1证明直判可用、约束修订在关系任务上失效）；修订走已修合同（revision_basis，扰动v2已验证）。这消灭rec侧感知自证（P5）。

**M4 条件贡献估计（已证效率）**
- v3条件贡献估计器（24次核查=均值47次的质量）保留为价值估计层——**估计器的正贡献已经成立，写论文可以立刻用**。

**M5 预算博弈（核心贡献所在，胜负手）**
- **稀缺构造**：核查预算设为提议总成本的约50–70%，分配必须取舍（P2）。
- **异质分配**：提议×核查者（Flash/Plus/GLM按校准档案）的匹配纳入分配问题（P4）——同预算下谁查什么。
- **交互感知集合分配**：SetAllocator的交互项在交互富集任务域（HotpotQA双文档）承担联合行动选择（P3）。
- **预登记获胜条件**（三条，任一成立即博弈有独立价值）：①交互富集域中，交互感知分配质量>按单份价值贪心top-k；②稀缺+异质下，均衡分配的质量/成本优于均匀分配与贪心；③预算收缩时博弈方案劣化曲线缓于固定顺序。

## 4. 验证路径（先便宜后昂贵，每步带证伪条件与止损）

| 阶段 | 内容 | 成本 | 证伪条件 |
|---|---|---|---|
| S1 离线稀缺重放 | 用v3已封存24主张响应，把预算砍到强制选择，离线重放博弈/贪心/中央/固定的分配差异 | 0元 | 若强制稀缺下分配仍完全一致→P2假设存疑，进S2前需解释 |
| S2 稀缺面板 | 自然主张+预算=半数核查成本，四分配策略真跑 | ~0.5元 | 博弈≤贪心且≤固定→分配层假设在该域证伪 |
| S3 异质面板 | 混核查者×稀缺，分配策略对照（含均匀分配） | ~1元 | 均匀分配≥博弈→P4假设证伪 |
| S4 交互富集域 | HotpotQA双文档子集：联合行动vs单行动、交互分配vs贪心 | ~2元 | 联合≤单份之和→P3在该域证伪 |
| S5 全量对照 | 重设计机制vs全对照重采主批+HotpotQA | ~15–20元 | 仅当S2–S4至少一条获胜条件成立才进入 |

S1 可以立刻做（全离线）；S5 只有在前面给出获胜信号时才值得花。**若S2–S4全部证伪**，得到的结论也是机制学级别的："博弈优势仅在稀缺×超加性×异质的交集内可能存在"——配合主批恒等结果，这仍是可发表的方法边界刻画，且比现在的负结果归因更完整。

## 5. 与现有资产的衔接

可复用：SetAllocator（交互项数学）、核查者校准档案（P4的现成数据）、linked接口+revision_basis合同（已验证）、条件贡献估计器（v3）、自然主张管线、全部封存/审计/回执复用基础设施。需新建：盲区提议器、需求触发器、独立验证prompt族、稀缺控制器——约500行代码+测试，均为代理侧工作。

## 6. 论文表述（结果出来前怎么写）

- **已成立、可写**：机制框架；三层归因（信息供给/动作选择/执行合同）；修复验证（扰动v2）；**贡献估计效率（v3：24 vs 47次核查）**；**更新链路可通（v3：7–8/24）**；各regime恒等结果及其理论解释（次模+无稀缺）。
- **假设、待验证**：博弈在满足P1–P5的regime中的分配优势（S2–S5）。
- **不写**："博弈优越性已验证"（当前无任何证据）；重采保证论；单因归因论。
- 中期报告按Codex回填框架组织（方法设计/实验设计/主结果/原因分析/改进验证/后续安排），保持"一个研究方法+一个系统实现"结构——本方案恰好为"方法改进"一节提供了有文献锚点和实验锚点的路线图。

## 7. 风险与诚实边界

- 本方案使博弈优势**可检验**，不保证成立；博弈优劣最终是经验问题。
- 自然任务的机会率本身偏低（QA检索目录推理空白、rec仅6/38可换入）——即使修通全链路，自然域增益幅度可能有限；交互富集域（HotpotQA）与受控机会域是价值展示的主战场。
- 修复后重跑不保证非零更新；若仍零，剩余原因是多元的（动作自证/稀缺/机会率/任务域），不单因归因。
- 所有阶段沿用既有纪律：预登记、封存评分、fail-closed、未知不重发、哈希链。
