# 证据获取激励机制：审查与修订设计

日期：2026-10-19。状态：设计审查，不是实验结果、预注册或已完成贡献。本轮不调用付费模型。

## 一、先明确研究究竟解释什么

研究问题只有一个：**在相同的信息获取工具和报告能力下，公开的贡献结算规则，能否使独立Agent形成稳定的证据获取分工，并以可接受的成本支持集体决策？**

这里包含三个不同对象，必须分别给出证据：

1. 数学机制：给定行动、支付和成本，是否存在稳定响应，Leader如何选择合同。
2. 执行协议：系统是否真正按规则访问来源、扣费、结算，实际策略是否接近模型响应。
3. 任务效果：获得的资料是否有用，最终结论是否改善，成本是否值得。

不能用第三项的准确率证明第一项，也不能用第一项的零后悔证明第三项。全文不预设检索优于直接回答，不预设正奖励优于零奖励。

AEIC用于记录假设、证据、推断和结论，是可审计的语义报告接口；本方案不把“四个字段必不可少”作为待证明结论。共识指固定聚合规则形成的集体结论，不意味着真实机器网络达成分布式一致性。

## 二、现有设计的深度审查

| 问题 | 为什么影响结论 | 修订决定 |
|---|---|---|
| 旧奖励成本网格存在严格劣势行动 | 实际选择不是收益最大化，不能称均衡 | 保留行为与失败证据，不追认均衡 |
| 以实际发现文档数重新归一化预算 | 新增文档改变所有已有文档的单价；上一稿没有给出相应存在性证明 | 主方案改为事先固定来源权重；未支付预算不再分配 |
| 把来源可追溯当事实验证 | 原文存在不代表支持结论，无关资料也能骗取过程信用 | 支付只解释为获取贡献，事实质量单独测量 |
| 私有来源与完全信息求解混用 | Agent不知道他人收益时，完全信息Nash不是其真实决策模型 | 首轮主试验采用公开收益元数据、私有正文；未知私人类型不纳入理论保证 |
| 收益由LLM引用成功率决定，却按确定表求解 | 结算存在随机性，离线单次结果不是行动前期望 | 首轮理论模型以执行器确定性获取凭据支付；语义报告不决定支付 |
| 虚拟分数被当作LLM实际效用 | 提示模型“最大化信用”不证明其真正服从 | 规范计算Agent与LLM自主选择分开报告 |
| 同步行动被写成必然收敛 | 势博弈存在均衡，不保证同步最佳响应收敛 | 主执行协议采用异步严格改进；同步自主选择仅作行为检验 |
| 离线枚举器替Agent选择 | 得到的是集中计算出的解，不是分散博弈过程 | 枚举只作校验；实际记录逐Agent局部偏离计算与更新 |
| 逐题看答案挑最优合同 | 实际部署无法访问本题真值，造成oracle泄漏 | 开发集选一个全局合同，测试集锁定执行 |
| 正确率不升便继续改某类题检查器 | 优化了答题环境，无法归因于激励机制 | 通用工具先冻结，所有条件同源同权限；失败保留 |
| 势函数与结算规则本身并非新理论 | 已有拥塞/福利分享博弈有成熟结果 | 明确引用；创新需由任务建模、审计执行和机制实证支撑 |

其中最后一项尤其重要：下面的势函数证明是保证设计自洽的工具，不应包装为首次提出势博弈或首次证明纯Nash存在。

## 三、修订后的最小模型

### 3.1 固定环境与信息结构

每题3个已注册Agent。每个Agent只有两个行动：D直接报告；R获取事先指定的来源包，再报告。任意合同下，R执行完全相同的检索、正文读取和报告路径。

在选择合同前，由不读取答案键的通用检索管线生成有限来源库S，并冻结快照、文档哈希、来源包T_i(D)=空集与T_i(R)、访问权限和费用。各Agent知道所有人的来源包ID、成本与支付规则，但行动前不能读取未授权正文，也不能看到同伴结论。公开“哪个来源属于哪个包”不等于公开来源内容。

这是完全信息的资源行动博弈，不是未知私人类型的贝叶斯博弈。来源内容、任务答案仍可未知；收益所需的元数据必须已知。若实际检索失败率、私人费用或可获取集合未知，不能直接套用本节定理。

冻结来源库是可复现实验环境，不代表完成了开放网络搜索。建库调用和下载开销单独计入，缓存读取与冷启动成本分别披露。主结果应同时提供共享建库开销计入前后的总成本。

### 3.2 合同与结算

合同只选择预算B。对固定来源库事先确定非负权重α_s，满足Σ_s α_s=1；首轮使用均匀权重，不根据正确答案或检索后的支持程度设权。空来源库不支付。

```text
w_s(B) = B α_s
n_s(a) = Σ_i 1[s ∈ T_i(a_i)]
p_i(a;B) = Σ_{s ∈ T_i(a_i)} w_s(B) / n_s(a)
u_i(a;B) = p_i(a;B) − c_i(a_i)
```

只有执行器签发的有效来源获取凭据才算贡献：绑定任务、Agent、来源哈希与执行记录。Agent自报来源、重复引用、复制同伴凭据均不能增加支付。实际费用按执行记录记录；理论c_i是事先冻结的决策费用，实际Token波动不能事后偷偷替换理论费用。

```text
Σ_i p_i(a;B) = Σ_{s:n_s(a)>0} w_s(B) ≤ B
```

没有人获取的来源，其奖励不支付，也不转分给其他来源。这一点与上一稿B/(已发现来源数)不同，是证明成立的重要条件。

理论主环境要求成功获取集合可由固定动作确定。缓存缺失、权限异常等执行失败必须中止该题的理论一致性判定并记录，不能悄悄换来源或补发凭据。未来若研究随机获取，应建立行动前随机模型并另证期望收益性质，不以一次回放替代。

### 3.3 为什么存在纯策略响应

令H_0=0，H_k=Σ_{j=1}^k 1/j。定义：

```text
Φ_B(a) = Σ_s w_s(B) H_{n_s(a)} − Σ_i c_i(a_i)
```

只有Agent i改变行动时：新增来源使势增加w_s/(原人数+1)；放弃来源使势减少w_s/原人数；未改变的来源人数不变。再扣除自己的费用变化，恰好得到：

```text
Φ_B(a'_i,a_-i) − Φ_B(a_i,a_-i)
  = u_i(a'_i,a_-i) − u_i(a_i,a_-i)
```

因此这是有限精确势博弈。势最大点至少存在一个，且任何势的单方局部最大点都是纯Nash。有限行动下，异步严格收益改进不会回到原状态，必然有限步终止于纯Nash。平收益更新不允许随意切换，以免出现循环。

这个证明只保证Follower子博弈的稳定性，不保证势最大点就是Leader收益最大点，不保证所有均衡质量一致，也不保证LLM会执行最佳响应。

方法依据：Rosenthal的拥塞博弈势函数，以及福利分享规则与均衡存在性的既有研究。本节是对当前合同的具体推导，不宣称新的一般定理。

### 3.4 Leader求解的严格口径

候选预算集合M必须有限、包含0，并在开发选择前冻结。对每个B枚举8种联合行动，求完整NE(B)。Leader目标为：

```text
V(B,a) = E[集体正确率]
         − λ_c E[实际总资源成本]
         − λ_p E[实际支付]
```

成本按固定单位换算。支付若只是内部配额转移，不应同时冒充外部API费用；λ_p可为0，但要说明其机会成本含义。支付和资源开销分别列出，避免双重计价。失败已计入未正确与实际成本时，不再重复添加失败惩罚。

```text
B_robust ∈ argmax_{B∈M} min_{a∈NE(B)} E_dev[V(B,a)]
```

主选择采用悲观均衡口径，乐观结果只作区间参照。实际异步协议可能只到其中一个均衡，应另报其实现值。最坏均衡上界/下界不是一个自动实现的均衡选择器。

若全部收益、质量期望已知且被精确计算，这给出“指定有限合同族、纯Follower均衡下的最优承诺”。实际质量来自有限开发样本，只能称估计模型上的有限合同最优解；测试集检验其泛化。不称所有合同、连续预算或真实世界的全局最优。

## 四、实际博弈过程如何发生

主协议不让中央枚举器分配最终行动：

1. Leader公开冻结合同、来源ID、费用与更新次序；报告生成器不接收合同文字。
2. Agent从公开、固定的初始行动开始。行动登记尚不执行收费检索。
3. 按固定轮转次序，每次只有一个Agent根据当前登记与自己的收益公式计算D/R；严格改善才修改登记。这里只公开行动/来源ID，不公开同伴答案。
4. 一整轮无人改善后停止，随后各自执行最终动作；未收敛或执行异常保留完整日志。
5. 执行器核验获取凭据并结算。Agent独立产生AEIC报告，统一按固定多数规则决定答案；无多数计弃答。
6. 独立审计器在事后枚举8种配置，检查实际终点的单方偏离收益，但不替换实际终点。

显式策略Agent的效用是我们设计的目标，适合验证规范计算机制。它不是“LLM天然追求积分”的发现。LLM自主选择在同一公开元数据下单独运行：不给它事后纠错，也不把错误选择改为理论最优。若其后悔较大，结论是该行为接口尚未实现近似均衡。

轮转和公告板有统一程序，但选择在各Agent进行，准确口径为逻辑分散决策。不得宣称无协调器P2P部署。轮次计算、选择调用与等待都进入系统成本；不能只统计最终报告调用。

## 五、反例复核：方案可能在哪里失败

### 反例1：稳定但完全没用

所有来源都无关，预算仍可能诱导获取，最终准确率不变而成本增加。模型仍可能正确预测均衡，但机制没有任务价值。保留这些题，允许Leader选择B=0，不用“获取率上升”替代有效性。

### 反例2：假多样性

两个网页复制同一错误内容，但哈希不同，仍获得两份来源信用。文档去重不等于语义独立。主张限于文档级贡献；另报近重复率与共同来源线索，不宣称已解决独立事实验证。

### 反例3：同步最佳响应振荡

两人竞争一个奖励w、各费用c且w/2<c<w。从无人检索出发，两人同时认为值得进入；从两人检索出发，两人又同时退出，产生循环。纯均衡实际是仅一人检索。故“存在纯均衡”绝不等于同步更新会收敛。

### 反例4：异步次序决定谁付出

同样的单来源例子，先更新者可能成为唯一检索者。交换次序可能改变分工乃至质量。固定主次序，开发阶段报告全部6种次序的敏感性；不能只展示最好的次序。测试不按答案选择次序。

### 反例5：账户真的扣费，模型却不在乎

执行器守恒只能证明资源账本真实，不能证明自主LLM最大化该效用。区分“规则执行正确”“规范策略收敛”“自主行为近似响应”。不再把三者合成一句已经实现激励相容。

### 反例6：均衡正确，最终答案仍错

Agent可能独立获取错误来源，或误读资料；多数票可能放大共同偏差。支付和势函数不含真值，不能推出正确率保证。真实质量必须通过独立问题集测量。

### 反例7：AEIC只是外壳

若普通JSON也能同样记录凭据，不能声称AEIC字段造成性能提升。本轮不再做缺乏功效的字段必要性证明；将AEIC定位为解释与追溯接口，机制证据来自贡献耦合、偏离收益和成本质量比较。

### 反例8：设计退化成昂贵的调度器

集中分配可能更便宜且质量相同。必须设同信息、同执行路径、匹配预算的集中式基线。若没有分散控制需求或效率优势，就限于“可审计的分散资源协调方案”，不宣称普遍优于调度。

## 六、实验组织：先证机制，再谈效果

### 阶段A：无API设计验证

验证支付不超预算、重复凭据无增益、未获得来源不支付、每条单方变化满足势差恒等式、所有小型实例存在纯Nash、异步严格改进终止。加入同步振荡反例，防止把同步流程写成收敛算法。

这只是程序与推导相互校验，不是实证有效性结果。现有旧结算模块还依赖support_status，与新主支付不一致，禁止直接拿它启动主实验。

### 阶段B：固定环境可用性与信息价值

6道明确标记的开发题，3 Agent，两种行动各2次，共72个报告执行单元。真正API调用还包含建库、查询、选择与修复，不能把72写成调用总量。

先观察D/R资料是否产生可测信息变化、解析与工具失败率、成本尺度。不要求R一定更准；如没有收益，先报告环境局限，不改成专用检查器再算同一机制实验。6题不足以证明提升或无效。

### 阶段C：合同与行为

冻结预算网格、资源单位、来源与Prompt哈希、数据划分、目标权重。主比较：零信用、同预算平均获取信用、固定预算来源分摊、开发选择的来源分摊。后两项才对应上述来源势博弈；其他结算也要逐一枚举响应，不能借用本合同的定理。

主机制指标：实际终点单方后悔、收敛轮数、来源覆盖、重复投入、结算正确率。显式策略与自主LLM分开。显式模块零后悔主要验证实现一致性，不能作为LLM行为发现。

次指标：集体正确率、弃答、来源相关性与支持测量、Token、调用、延迟、支付。语义支持裁判须声明误差与抽查范围，不能作为付款真值。

### 阶段D：一次性独立检验

开发集只选一个合同；未见测试锁定合同与协议。开发质量的抽样误差会影响Leader选择，需报告不同合同的质量成本区间、均衡选择区间和选择稳定性，不只报最优点。

问题为统计聚类单位；同题Agent与重复运行不是独立样本。先用开发方差定样本量，再冻结主对比；既有已检查题不得冒充新测试。集中式、随机和固定配额单列为策略基线，不混同合同唯一变化的比较。

## 七、进入新采集前的阻断项

- 固定来源库与权限清单；泛化检索器版本和完整建库成本。
- 新支付实现与旧support_status支付严格分离；凭据不可复制的验证测试。
- 明确决策费用单位与实际资源账本；支付的机会成本及是否兑现。
- 固定来源包、α、预算网格、初始化与异步更新次序。
- 固定报告Prompt、模型别名及返回版本记录；不宣称别名永不升级。
- 审计历史题目接触记录，登记开发/测试ID与主统计对比。
- 确定Leader权重；明确可接受的质量成本折中，而不是出结果后选权重。

以上完成前不启动新的正式付费采集。本审查没有冻结这些尚缺参数。

## 八、对现有成果的处理

450题主实验保留其已有证据边界；不凭新模型追认为均衡实验。旧网格保留行为失败分析。合成题、茶叶检查器与已曝光小样本保留为探索或工程案例，不挤入最终主比较。

研究论文讨论通用机制与实证；影视系统是毕业设计的重要应用与工程部分，专利依托机制在系统中的实现。现阶段不把本设计的定理、协议或预期实验写入“已经完成”的论文结果。新研究是否支持更强主张，要等执行证据。

## 九、复核后的决定

保留：公开合同、真实获取动作、多Agent收益耦合、AEIC追溯、固定集体聚合、Leader有限合同选择。

修改：固定来源权重替代事后预算归一化；公开收益元数据替代模糊私有类型；异步严格改进替代同步收敛假设；确定性获取凭据替代LLM语义裁判付款。

暂不声称：真实LLM理性、事实真实性保证、AEIC字段必要性、混合/连续合同全局最优、未知私人信息均衡、影视推荐质量显著提升。

**这条路线能把“求解对象”和“实际过程”对上，但不能保证最后出现正奖励最优或准确率提升。若实验不支持这些结论，正确收口是缩小主张，而不是再找一种让Agent检索的提示。**
