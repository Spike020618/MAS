# 可学习信息生产协调：锁定的小规模执行方案

## 问题与范围

不再仅对固定答案求均衡。检验程序化协调是否能更好选择真实的推理资源行动，并与普通优化比较。固定 DeepSeek 后端，模型权重不训练；训练的是外部有限策略表。属于借鉴 ECON 的最小工程研究原型，不是 ECON 复现、神经网络信念训练或新的理论贡献。

严格 Consensus Game 全文似然复现仍受评分后端限制；此前 API 编码概率小验证不能代替它。可学习协调独立执行，不把旧 450 题效果用于新方法证明。

## 输入与行动

新准备 36 个来源隔离输入，按预先哈希顺序从各训练/测试域选 4 题：训练 12、测试 12，三域平衡，不按错误或分歧选题。历史精确来源/规范化题干筛查，不保证语义及预训练未见。

每题先得到三个独立快速报告；一个作为固定角色，另两个程序主体可保留各自报告（0）或调用 thinking-enabled 高推理资源路径（1）。四种组合 00、01、10、11 共享候选与多数规则。没有伪装外部查证，升级只是推理模式变化。所有控制器计入三个共同初始调用，再计实际选中升级调用。

每题完整潜在输出池最多五次物理调用，总上限 120；不重试，不使用 Qwen。测试时，博弈决策在初始报告后封存，再先执行选中升级，最后补采其他路径作为同菜单基线。补采不反馈到当前已选决策。

## 目标与学习

训练收益：集体正确指示减本人升级 Token 成本。成本系数锁定为每 Token 1/50000，即每千 Token 0.02 正确收益单位。这是声明的成本偏好，不是市场价格，另报原始正确率、Token、调用与延迟；不能仅依赖综合分宣称优越。

固定初始成本与行动无关，因此不进入行动优化目标，但进入总成本报告。精确势函数为正确收益减两主体升级成本。这里的共同正确收益对应明确团队任务，不奖励字段完整、新颖词面或无效调用。

仅用训练标签拟合四组合经验收益表；上下文只允许初始有效一致/非一致两种状态，不用领域 ID、题干内容或答案键。状态不足三例回退全局训练表。

博弈控制器从 00 开始，按角色 0、1 顺序执行严格获益的单边最优响应，精确平局保留。有限经验势单调增加，可检验训练表无获利偏离；不保证全局最优或真实测试分布上的均衡，更不假设自然语言模型天然自利理性。

## 必要对照

- 四种固定组合，含零升级与全部升级。
- 四组合均匀随机的解析期望。
- 与博弈同升级次数的随机角色分配期望。
- 普通集中式经验优化：同一训练反馈、同一上下文、同一四组合，直接找全局经验目标最大值；同样采用固定字典序平局规则。

集中式优化绝不是故意削弱的对照；训练表上其目标不低于博弈是预期数学事实。重点是测试表现、成本及策略差异。如果与集中式优化相同，就不能宣称博弈独立增量。

训练结束封存策略，之后不更新测试策略；测试标签在所有读出封存后才读取。比较测试正确数与目标；测试样本仅 12，不以未显著差异证明等效，不扩大到正式 300 题，不在本批上改成本系数追正结果。

## 失败与完成标准

API 账单/身份变化/未知传输错误保留日志并停止新调用；已记录成功槽可恢复。不虚构缺失结果。

工程验收包括行动路径、冻结策略、测试标签隔离、完整调用记账、程序收益与势的对应、各对照、测试及历史证据保留。工程完成不等于研究成功。若博弈未优于普通优化，明确结论为本配置未展示博弈必要性，不继续追加包装。
